# VitePress + ai-i18n-tools

此示例展示了 **`vitepress`** 输出预设：英语源页面位于 `docs/`，翻译副本写入 `docs/pt-BR/` 和 `docs/zh-Hans/`。

## 您将看到的内容

- `init -t ui-vitepress` 风格配置与 `docsOutput.style: "vitepress"`
- 仅两个目标语言（`pt-BR`，`zh-Hans`）以便快速、可读的演示
- 提交的翻译使得 `pnpm run docs:dev` 无需 API 密钥即可工作
