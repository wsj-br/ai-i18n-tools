# VitePress + ai-i18n-tools

Este exemplo mostra o preset de saída **`vitepress`**: páginas de origem em inglês estão disponíveis em `docs/` e cópias traduzidas são escritas em `docs/pt-BR/` e `docs/zh-Hans/`.

## O que você verá

- Configuração estilo `init -t ui-vitepress` com `docsOutput.style: "vitepress"`
- Apenas dois locais-alvo (`pt-BR`, `zh-Hans`) para uma demonstração rápida e legível
- Traduções comprometidas para que `pnpm run docs:dev` funcione sem uma chave de API
