# Começando

## Executar o site

A partir de `examples/nextra-docs`:

```bash
pnpm install
pnpm run dev
```

Abra [http://localhost:3070/](http://localhost:3070/) e mude os idiomas com o menu de idiomas.

## Traduzir documentação

```bash
echo "OPENROUTER_API_KEY=sk-or-..." > .env
pnpm run i18n:sync
```

Configuração: [`ai-i18n-tools.config.json`](https://github.com/wsj-br/ai-i18n-tools/blob/main/examples/nextra-docs/ai-i18n-tools.config.json).

## Recapitulação do layout

| Artefato | Fonte | Traduzido com |
| --- | --- | --- |
| Páginas MDX | `content/en/` | `translate-docs` (`style: "Nextra"`) |
| Strings de tema | `app/_dictionaries/en.ts` | `translate-docs` (`nextraDictionaryPath`) |
| Rótulos da barra lateral | `content/en/**/_meta.ts` | `translate-docs` |
