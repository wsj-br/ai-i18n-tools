# Nextra + ai-i18n-tools

Este exemplo mostra o preset de saída **`nextra`**: páginas de origem em inglês estão localizadas em `content/en/` e cópias traduzidas são escritas em `content/pt-BR/` e `content/zh-Hans/`.

## O que você verá

- Configuração estilo `init -t ui-nextra` com `docsOutput.style: "Nextra"`
- Apenas dois locais de destino (`pt-BR`, `zh-Hans`) para uma demonstração rápida e legível
- Traduções confirmadas para que `pnpm run dev` funcione sem uma chave de API
- Módulo de dicionário de tema (`app/_dictionaries/en.ts`) e rótulos da barra lateral (`content/en/**/_meta.ts`) traduzidos via `translate-docs` (sem sidecars JSON)
