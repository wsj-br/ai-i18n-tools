# Nextra + ai-i18n-tools

Este exemplo mostra o preset de saída **`nextra`**: páginas de origem em inglês estão localizadas em `content/en/` e cópias traduzidas são escritas em `content/pt-BR/` e `content/zh-Hans/`.

## O que você verá

- Configuração estilo `init -t ui-nextra` com `docsOutput.style: "Nextra"`
- Apenas dois locais-alvo (`pt-BR`, `zh-Hans`) para uma demonstração rápida e legível
- Traduções comprometidas para que `pnpm run dev` funcione sem uma chave de API
- Dicionário de tema JSON (`app/_dictionaries/`) e rótulos da barra lateral (`i18n/meta.*.json`) traduzidos via `json[]`
