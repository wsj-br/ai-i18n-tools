# Nextra + ai-i18n-tools

This example shows the **`nextra`** output preset: English source pages live under `content/en/` and translated copies are written to `content/pt-BR/` and `content/zh-Hans/`.

## What you will see

- `init -t ui-nextra`-style config with `docsOutput.style: "nextra"`
- Two target locales only (`pt-BR`, `zh-Hans`) for a fast, readable demo
- Committed translations so `pnpm run dev` works without an API key
- Theme dictionary JSON (`app/_dictionaries/`) and sidebar labels (`i18n/meta.*.json`) translated via `json[]`
