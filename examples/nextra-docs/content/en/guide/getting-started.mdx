# Getting started

## Run the site

From `examples/nextra-docs`:

```bash
pnpm install
pnpm run dev
```

Open [http://localhost:3070/](http://localhost:3070/) and switch locales with the language menu.

## Translate documentation

```bash
echo "OPENROUTER_API_KEY=sk-or-..." > .env
pnpm run i18n:sync
```

Config: [`ai-i18n-tools.config.json`](https://github.com/wsj-br/ai-i18n-tools/blob/main/examples/nextra-docs/ai-i18n-tools.config.json).

## Layout recap

| Artifact | Source | Translated with |
| --- | --- | --- |
| MDX pages | `content/en/` | `translate-docs` (`style: "nextra"`) |
| Theme strings | `app/_dictionaries/en.json` | `translate-json` |
| Sidebar labels | `i18n/meta.en.json` | `translate-json` |
