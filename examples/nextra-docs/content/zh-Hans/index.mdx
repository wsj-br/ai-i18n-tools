# Nextra + ai-i18n-tools

此示例显示了 **`nextra`** 输出预设：英语源页面位于 `content/en/`，翻译副本写入 `content/pt-BR/` 和 `content/zh-Hans/`。

## 您将看到的内容

- `init -t ui-nextra`风格的配置，带有`docsOutput.style: "Nextra"`
- 仅支持两种目标语言环境（`pt-BR`、`zh-Hans`），用于快速、可读的演示
- 已提交的翻译，因此`pnpm run dev`无需API密钥即可工作
- 通过`translate-docs`翻译的主题词典模块（`app/_dictionaries/en.ts`）和侧边栏标签（`content/en/**/_meta.ts`）（无JSON伴随文件）
