# Nextra + ai-i18n-tools

此示例显示了 **`nextra`** 输出预设：英语源页面位于 `content/en/`，翻译副本写入 `content/pt-BR/` 和 `content/zh-Hans/`。

## 您将看到的内容

- `init -t ui-nextra` 风格配置与 `docsOutput.style: "Nextra"`
- 仅两个目标区域（`pt-BR`，`zh-Hans`）以便快速、可读的演示
- 已提交的翻译，因此 `pnpm run dev` 无需 API 密钥即可工作
- 主题词典模块（`app/_dictionaries/en.ts`）和侧边栏标签（`content/en/**/_meta.ts`）通过 `translate-docs` 翻译（无 JSON 附属文件）
