# 入门

## 运行站点

从 `examples/Fumadocs-docs`： 

```bash
pnpm install
pnpm run dev
```

打开 [http://localhost:3080/docs](http://localhost:3080/docs) 并使用语言菜单切换区域设置。

## 翻译文档

```bash
echo "OPENROUTER_API_KEY=sk-or-..." > .env
pnpm run i18n:sync
```

配置：[`ai-i18n-tools.config.json`](https://github.com/wsj-br/ai-i18n-tools/blob/main/examples/Fumadocs-docs/ai-i18n-tools.config.json)。

## 布局回顾

| 工件 | 来源 | 翻译工具 |
| --- | --- | --- |
| MDX 页面 | `content/docs/` | `translate-docs` (`style: "Fumadocs"`，点解析器) |
| 侧边栏标签 | `content/docs/meta.json` | `translate-docs` |
| UI 字符串 | `lib/layout.shared.ts` | `translate-docs` → `lib/i18n/ui.{locale}.json` |

返回[主页](/docs)。
