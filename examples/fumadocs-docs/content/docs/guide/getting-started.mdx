# Getting started

1. Run `pnpm run i18n:sync` to translate MDX pages, `meta.json`, and UI catalog strings.
2. Run `pnpm run dev` and open [http://localhost:3080/docs](http://localhost:3080/docs).

Links use Fumadocs routes such as [the home page](/docs).
