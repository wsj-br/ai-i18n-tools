# Fumadocs + ai-i18n-tools

This example shows the **`fumadocs`** output preset with the **dot** parser: English source pages live at `content/docs/*.mdx` and translated copies are written as locale suffixes (`*.pt-BR.mdx`, `*.zh-Hans.mdx`).

## What you will see

- `init -t ui-fumadocs`-style config with `docsOutput.style: "fumadocs"`
- Two target locales only (`pt-BR`, `zh-Hans`) for a fast, readable demo
- Committed translations so `pnpm run dev` works without an API key
- Sidebar labels (`meta.json`) and UI catalog (`lib/i18n/ui.{locale}.json`) translated via `translate-docs`
