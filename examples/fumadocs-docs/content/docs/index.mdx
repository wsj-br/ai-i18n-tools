# Welcome

This example uses the **dot** i18n parser: English MDX lives at the collection root (`content/docs/*.mdx`), and translations are written as locale suffixes (`*.pt.mdx`, `*.zh.mdx`).

See [Getting started](/docs/guide/getting-started) for setup steps.
