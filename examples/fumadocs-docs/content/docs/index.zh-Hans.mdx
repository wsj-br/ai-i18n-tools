# Fumadocs + ai-i18n-tools

此示例展示了使用 **dot** 解析器的 **`fumadocs`** 输出预设：英文源页面位于 `content/docs/*.mdx`，翻译副本则以区域设置后缀（`*.pt-BR.mdx`、`*.zh-Hans.mdx`）的形式写入。

## 您将看到什么

- 采用 `docsOutput.style: "Fumadocs"` 的 `init -t ui-fumadocs` 风格配置
- 仅支持两种目标语言环境 (`pt-BR`, `zh-Hans`)，以实现快速、可读的演示
- 已提交翻译，因此 `pnpm run dev` 无需 API 密钥即可工作
- 侧边栏标签 (`meta.json`) 和 UI 目录 (`lib/i18n/ui.{locale}.json`) 通过 `translate-docs` 翻译
