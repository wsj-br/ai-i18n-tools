# Fumadocs + ai-i18n-tools

Este exemplo mostra o preset de saída **`fumadocs`** com o parser **dot**: as páginas de origem em inglês estão em `content/docs/*.mdx` e as cópias traduzidas são escritas como sufixos de localidade (`*.pt-BR.mdx`, `*.zh-Hans.mdx`).

## O que você verá

- Configuração estilo `init -t ui-fumadocs` com `docsOutput.style: "Fumadocs"`
- Apenas dois locais de destino (`pt-BR`, `zh-Hans`) para uma demonstração rápida e legível
- Traduções confirmadas para que `pnpm run dev` funcione sem uma chave de API
- Rótulos da barra lateral (`meta.json`) e catálogo da UI (`lib/i18n/ui.{locale}.json`) traduzidos via `translate-docs`
