# Modèles

L'onglet **Modèles** classe les modèles de chat du fournisseur actif afin que vous puissiez choisir `translationModels` sans copier manuellement leurs ID. Il utilise le même classement que [`suggest-models`](/fr/reference/cli-commands/models#suggest-models). La présentation détaillée, qui explique notamment pourquoi la liste contient plusieurs modèles, se trouve dans [Modèles d'IA](/fr/guide/ai-models).

La page est divisée en deux volets. La **Configuration actuelle** est la chaîne de secours déjà enregistrée pour le fournisseur sélectionné. La première ligne est essayée en premier. Les **Suggestions** sont le catalogue classé que vous pouvez consulter, réorganiser et enregistrer. Changer le fournisseur ou la priorité recharge les deux volets. Un identifiant configuré qui est absent du catalogue apparaît toujours dans la **Configuration actuelle**, marqué comme n'étant pas dans le catalogue.

Choisissez **Qualité** ou **Prix**. La qualité trie par l'indice ChrF et Arena et traite la colonne de frontière comme une étiquette. Le prix liste le niveau 1 du moins cher au plus cher, puis le niveau 2 de la même manière, et ainsi de suite. Il maintient toujours un seuil de qualité, de sorte qu'un modèle bon marché sans mesure reste en dessous des modèles qui ont des scores. Lorsque la configuration a plus d'un fournisseur, un menu **Fournisseur** apparaît ; le fournisseur par défaut est celui avec lequel le tableau de bord a été démarré (`provider`, ou `-P` / `--provider` sur la commande `dashboard`). Les poids optionnels se trouvent dans [`modelSuggestion`](/fr/reference/configuration#modelsuggestion-optional).

Les deux volets partagent les colonnes de score et de prix : identifiant du modèle, indice (le score de qualité multiplié par 100), ChrF mesuré, score Arena mesuré, prix d'entrée, prix de sortie, prix combiné en USD par million de jetons, et niveau de frontière. Une mesure manquante est un tiret cadratin. Passez la souris sur un en-tête de colonne dans l'un ou l'autre volet pour voir une courte description de cette colonne. Passez la souris sur une valeur de frontière de 2 ou plus pour voir quel modèle de niveau 1 domine cette ligne. Le nombre indique la profondeur de cette chaîne, et non la distance de l'indice par rapport au meilleur modèle. Un identifiant qui répète le ChrF, le score Arena et les prix des jetons d'une autre ligne est omis des **Suggestions**. L'identifiant le plus court est conservé, et un identifiant sans date l'emporte sur un identifiant daté. Un alias configuré apparaît toujours dans la **Configuration actuelle**. Une égalité exacte sur le prix combiné et l'indice partage le niveau. Comment lire la colonne : [Lecture de la colonne de frontière](/fr/guide/ai-models#reading-the-frontier-column).

La **Configuration actuelle** ajoute une colonne d'ordre. Ce nombre est la place du modèle dans la chaîne enregistrée.

Les **Suggestions** ajoutent des contrôles de réorganisation, une case à cocher et un rang. Le numéro de rang est la place du modèle dans le classement complet, avant les filtres ci-dessous. Faites glisser la poignée d'une ligne, ou utilisez ses boutons haut et bas, pour modifier sa place dans ce tableau. **Mettre à jour** charge à nouveau l'ordre de classement.

Les contrôles se trouvent dans trois cartes. **Classement** contient le menu de priorité (et le menu du fournisseur lorsque la configuration a plus d'un fournisseur). **Filtres** contient **Prix combiné max**, **Delta d'indice min** et **Mettre à jour**. **Actions** contient **Copier JSON** et **Mettre à jour la configuration**. Appuyez sur Entrée dans un champ numérique pour actualiser le tableau. Changer un menu fait de même.

**Prix combiné max** conserve les modèles dont le prix combiné `(3 × input + output) / 4` par million de jetons est au maximum de ce nombre de dollars américains. Un modèle sans prix combiné est exclu. **Delta d'indice min** ne conserve un modèle que si son indice diffère du modèle précédemment conservé d'au moins ce nombre de points. Le premier modèle restant est toujours conservé. Laissez l'une ou l'autre des cases vides pour ignorer ce filtre. Dans un classement de qualité, définissez les deux avant **Mettre à jour la configuration** : le plafond de prix maintient une solution de repli dans un budget, et l'écart d'indice exclut un modèle qui n'est qu'à un petit pas de celui qui le précède. Une ligne dominée sous le plafond peut toujours rester. La colonne de frontière est ce qui le montre.

Cochez les modèles que vous souhaitez. La ligne d'état indique combien sont sélectionnés, par exemple `8 models selected.`. Le nombre affiché dans l'en-tête de colonne de la case à cocher (par défaut 8) indique combien de premières lignes cette case à cocher sélectionne. La cocher sélectionne ces lignes. La décocher décoche toutes les cases à cocher. Les lignes cochées, de haut en bas, constituent l'ordre de repli. **Mettre à jour la configuration** demande confirmation, copie la configuration actuelle vers `ai-i18n-tools.config.{timestamp}.backup.json` à côté, puis écrit cet ordre dans `providers.<selected>.translationModels`. `uiModels` et `localeModels` restent inchangés. **Copier le JSON** place le même fragment `{ "translationModels": [...] }` dans le presse-papiers. `suggest-models --apply` écrit le même type de sauvegarde.

Le premier chargement télécharge languagebench, Arena et models.dev lorsque le cache est vide, ce qui peut prendre un certain temps. Les chargements ultérieurs réutilisent le cache de 7 jours situé à `<cacheDir>/benchmark-scores.json`. L'onglet ne possède pas de bouton d'actualisation. Actualisez le cache depuis l'interface en ligne de commande avec `ai-i18n-tools suggest-models --refresh`, puis rechargez l'onglet. La même commande peut afficher ou appliquer la liste.
