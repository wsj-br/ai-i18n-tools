# 统计

**统计**选项卡显示文档缓存和 UI 字符串目录的只读聚合。数据与命令行上的 `ai-i18n-tools statistics` 匹配。

使用它来回答：*翻译了多少内容，使用了哪些模型，以及存在哪些空白？*

<a id="documentation-cache"></a>
## 文档缓存

**摘要卡片：**

| 卡片 | 含义 |
| --- | --- |
| 总段数 | 所有缓存的文档段行 |
| 过期 / 活跃 | 自创建以来从未使用过的段与至少使用过一次的段 |
| 跟踪文件 / 唯一文件路径 | 缓存中的文件计数 |
| 使用的模型 | 不同的翻译模型 |
| 词汇表条目 | 用户词汇表 CSV 中的行数（配置时） |

**表格：**

- **按语言环境划分的段** — 每个目标语言环境的计数，包含过期/活跃细分
- **按模型划分的段** — 每个模型的计数
- **模型 × 语言环境矩阵** — 完整交叉表（与 CLI `--max-columns` 限制在终端输出中相同）

<a id="ui-strings"></a>
## UI 字符串

当 `strings.json` 可用时显示：

| 部分 | 含义 |
| --- | --- |
| 单数与复数计数 | 总非复数和复数组条目 |
| 每个语言环境的单数覆盖率 | 每个语言环境有多少单数字符串有翻译 |
| 每个语言环境的复数完整性 | 有多少复数组具有所有必需的 CLDR 形式 |
| 按模型 / 模型 × 语言环境 | 与文档缓存相同的矩阵布局 |

<a id="no-editing-on-this-tab"></a>
## 此选项卡不可编辑

统计信息是只读的。要更改数据，请使用其他仪表板选项卡或重新运行翻译命令，然后重新加载仪表板。

对于脚本输出，请运行：

```bash
ai-i18n-tools statistics
# Optional: widen model × locale tables
# ai-i18n-tools statistics --max-columns 12
```
