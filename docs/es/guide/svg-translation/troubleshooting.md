# Solución de problemas de SVG

Consulte también [Solución de problemas de imágenes y capturas de pantalla](/guide/images-and-screenshots/troubleshooting).

- **Fuentes y salidas SVG en el mismo directorio** — mantenga `svg.sourcePath` y `svg.outputDir` separados.
- **URL estáticas absolutas de Docusaurus para SVG colocados** — use rutas relativas `../assets/` desde el principio.
