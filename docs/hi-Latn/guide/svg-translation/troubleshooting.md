# SVG samasya-nivaran (troubleshooting)

Isko bhi dekhen [Images & Screenshots troubleshooting](/guide/images-and-screenshots/troubleshooting).

- **SVG sources aur outputs ek hi directory mein** — `svg.sourcePath` aur `svg.outputDir` ko alag rakhen.
- **Colocated SVGs ke liye Absolute Docusaurus static URLs** — shuru se hi relative `../assets/` paths ka upyog karen.
