# UI 문자열 및 복수형

**UI 문자열** 및 **UI 복수형** 탭은 `strings.json` 카탈로그의 행을 편집합니다. 대시보드 변경 사항은 SQLite 문서 캐시가 아닌 해당 파일에 직접 기록됩니다.

`translate-ui` 또는 `sync` 후에 UI 레이블 또는 복수형에 수동 수정이 필요한 경우 이 탭을 사용하십시오.

<a id="ui-strings-tab"></a>
## UI 문자열 탭

`strings.json`에서 복수형이 아닌 항목을 나열합니다. 문자열 ID 및 로케일당 한 행입니다.

<a id="filters"></a>
### 필터

| 필터 | 목적 |
| --- | --- |
| **ID/해시** | 문자열 ID 또는 해시 |
| **파일 이름(부분)** / **파일 경로 선택** | 소스 파일 범위 |
| **소스 포함** / **번역 포함** | 텍스트 부분 문자열 |
| **로케일** | 단일 로케일 또는 모두 |
| **모델** | 번역을 생성한 모델 |

<a id="edit"></a>
### 편집

1. 행에서 편집 아이콘을 클릭합니다.
2. 번역된 텍스트를 변경하고 저장합니다.

항목의 `models[locale]`이(가) `user-edited`(으)로 설정되어 있습니다. 일반 `sync` 또는 `translate-ui`을(를) 실행하여 플랫 로케일 파일(`de.json` 등)을 새로 고치십시오. **절대** `--force`을(를) 사용하지 마십시오. 모든 항목을 다시 번역하여 수동 수정을 덮어쓸 수 있습니다.

`glossary.autoAddUserEditedToGlossary`가 `true`(기본값)인 경우 다음 `translate-ui` 또는 `sync`는 사용자 용어집 CSV에 편집 내용을 자동으로 추가할 수 있습니다. [구성](/reference/configuration#glossary)을 참조하십시오.

<a id="delete"></a>
### 삭제

- **행 삭제 아이콘** — 항목에서 하나의 로케일 버킷을 제거합니다.
- **필터링된 항목 삭제** — 현재 필터와 일치하는 모든 로케일 버킷을 대량 삭제합니다.

<a id="log-links"></a>
### 로그 링크

🔗 컨트롤은 항목의 `locations` 배열에서 소스 파일:줄 위치를 터미널에 출력합니다.

<a id="ui-plurals-tab"></a>
## UI 복수형 탭

복수형 그룹 항목(`"plural": true`의 `strings.json`)을 나열합니다. 각 행은 한 로케일의 기수 형식(`one`, `other` 및 로케일별 형식)을 보여줍니다.

<a id="filters-1"></a>
### 필터

UI 문자열 탭과 동일하며, 다음이 추가됩니다.

| 필터 | 목적 |
| --- | --- |
| **완료 / 미완료** | 선택한 로케일에 필요한 모든 CLDR 형식이 있는지 여부 |

미완료 행은 해당 로케일에 필요한 형식 중 하나 이상이 누락되었습니다.

<a id="edit-1"></a>
### 편집

1. 행에서 편집 아이콘을 클릭합니다.
2. 모달에서 각 CLDR 형식을 편집합니다(형식당 하나의 텍스트 영역).
3. 저장 — 빈 형식 문자열은 저장 시 제거됩니다.

항목의 `models[locale]`이(가) `user-edited`(으)로 설정됩니다. 나중에 일반 `sync` 또는 `translate-ui`(을)를 실행합니다(`--force` 아님).

<a id="other-columns"></a>
### 기타 열

- **형식** — `one: "…"`, `other: "…"` 등을 표시합니다.
- **`zeroDigit` 배지** — 소스가 숫자 0 복수형 패턴을 사용할 때 읽기 전용 표시기입니다.

필수 형식은 로케일별 CLDR 규칙(`requiredPluralFormsByLocale`)에서 가져옵니다.

<a id="delete-1"></a>
### 삭제

UI 문자열과 동일: 로케일별 삭제 또는 **필터링된 항목 삭제** 대량 작업.
