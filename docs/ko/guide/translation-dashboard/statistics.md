# 통계

**통계** 탭은 문서 캐시 및 UI 문자열 카탈로그에 대한 읽기 전용 집계를 보여줍니다. 데이터는 명령줄의 `ai-i18n-tools statistics`와 일치합니다.

이것을 사용하여 다음 질문에 답할 수 있습니다. *얼마나 번역되었고, 어떤 모델이 사용되었으며, 어떤 부분이 부족한가?*

<a id="documentation-cache"></a>
## 문서 캐시

**요약 카드:**

| 카드 | 의미 |
| --- | --- |
| 총 세그먼트 | 캐시된 모든 문서 세그먼트 행 |
| 오래됨 / 활성 | 생성 이후 한 번도 재사용되지 않은 세그먼트 vs. 한 번 이상 재사용된 세그먼트 |
| 추적된 파일 / 고유 파일 경로 | 캐시의 파일 수 |
| 사용된 모델 | 고유한 번역 모델 |
| 용어집 항목 | 사용자 용어집 CSV의 행 수 (구성된 경우) |

**테이블:**

- **로케일별 세그먼트** — 대상 로케일별 개수, 오래됨/활성 분류 포함
- **모델별 세그먼트** — 모델별 개수
- **모델 × 로케일 매트릭스** — 전체 교차표 (CLI `--max-columns` 터미널 출력 제한과 동일)

<a id="ui-strings"></a>
## UI 문자열

`strings.json`를 사용할 수 있을 때 표시됩니다.

| 섹션 | 의미 |
| --- | --- |
| 단수 vs 복수 개수 | 총 단수 및 복수 그룹 항목 |
| 로케일별 단수 적용 범위 | 로케일별로 번역된 단수 문자열 수 |
| 로케일별 복수 완전성 | 필요한 모든 CLDR 형식을 가진 복수 그룹 수 |
| 모델별 / 모델 × 로케일 | 문서 캐시와 동일한 매트릭스 레이아웃 |

<a id="no-editing-on-this-tab"></a>
## 이 탭에서는 편집할 수 없습니다.

통계는 보기 전용입니다. 데이터를 변경하려면 다른 대시보드 탭을 사용하거나 번역 명령을 다시 실행한 다음 대시보드를 다시 로드하십시오.

스크립트된 출력을 위해 다음을 실행합니다.

```bash
ai-i18n-tools statistics
# Optional: widen model × locale tables
# ai-i18n-tools statistics --max-columns 12
```
