# 용어집

**용어집** 탭은 사용자 용어집 CSV(설정의 `glossary.userGlossary`)를 편집합니다. 여기의 항목은 `translate-ui`, `proofread-ui`, `translate-docs`에 대한 용어 힌트입니다(공유 용어집을 통해). 간결한 UI 레이블 약어(예: `Size` → `Tam` / `Tam.`)는 UI 번역을 위해 유지되지만 문서 프롬프트를 빌드할 때는 건너뛰므로, 모델이 markdown/MDX에서 만들어낸 <code v-pre>{{…}}</code> 토큰을 생성하도록 유도하지 않습니다.

`glossary.userGlossary`이(가) 구성되지 않은 경우 탭이 숨겨집니다.

<a id="csv-columns"></a>
## CSV 열

| 열 | 의미 |
| --- | --- |
| **원본 언어 문자열** | 원본 용어 또는 구문 |
| **로캘** | 대상 로캘 또는 모든 로캘에 대한 `*` |
| **번역** | 선호하는 번역 |
| **강제** | 선택하면 용어가 주어진 대로 정확하게 번역되어야 합니다 |

<a id="add-a-row"></a>
## 행 추가

탭 상단의 양식을 사용합니다.

1. **원본**, **로캘**(`*` 또는 대상 로캘 코드) 및 **번역**을(를) 입력합니다.
2. 선택적으로 **강제**를(을) 선택합니다.
3. **추가**를(을) 클릭합니다.

CSV 파일은 아직 존재하지 않는 경우 첫 번째 추가 시 생성됩니다.

<a id="edit-or-delete"></a>
## 편집 또는 삭제

- **인라인 편집** — 테이블에서 필드를 직접 변경하고 해당 행에서 **저장**을(를) 클릭합니다.
- **삭제** — 삭제 컨트롤로 행을 제거합니다.

변경 사항은 다음 `translate-ui`, `proofread-ui`, `translate-docs` 또는 `sync` 실행 시 적용됩니다.

<a id="filters"></a>
## 필터

**원본 텍스트**, **로캘**(`*` 포함) 또는 **번역 텍스트** 부분 문자열로 필터링한 다음 **적용**을(를) 클릭합니다.

<a id="dashboard-edits-and-glossary-auto-add"></a>
## 대시보드 편집 및 용어집 자동 추가

**UI 문자열** 또는 **UI 복수형** 탭에서 UI 문자열을 수정하면 다음 `translate-ui` 실행 시 `glossary.autoAddUserEditedToGlossary`이(가) `true`인 경우 해당 수정 사항을 용어집에 자동으로 추가할 수 있습니다. 용어집 탭을 사용하여 자동으로 추가된 행을 검토, 조정 또는 제거합니다.
