# कोडिंग-एजेंट कौशल

एक इंस्टाल हर उपभोक्ता कौशल को कॉपी करता है। [साझा कौशल](https://github.com/wsj-br/ai-i18n-tools/tree/main/skills/ai-i18n-tools) एक एजेंट को सिखाता है कि `sync` के साथ `ai-i18n-tools` को कैसे इंस्टॉल और बनाए रखा जाए, और केवल उस संदर्भ को लोड करता है जो कार्य से मेल खाता है। प्रत्येक वर्कफ़्लो एक अलग स्लैश कमांड है, जैसे `/ai-i18n-vitepress`।

npm पैकेज या स्टैंडअलोन निष्पादन योग्य को इंस्टॉल करने से कौशल पंजीकृत नहीं होते हैं। प्रत्येक एजेंट के लिए एक इंस्टाल विधि का उपयोग करें।

<a id="install-with-the-skills-cli"></a>
## स्किल्स सीएलआई के साथ इंस्टॉल करें

यह वह इंस्टाल है जिसका उपयोग तब करना है जब Node.js 22.20 या नया हो। इस पैकेज का अपना सीएलआई Node.js 22.16 की अनुमति देता है, जो स्किल्स सीएलआई के लिए बहुत पुराना है। 22.16 से 22.19 तक, या Node.js रहित मशीन पर, [कौशल निर्देशिका डाउनलोड करें](#download-the-skill-directory) का उपयोग करें।

उस प्रोजेक्ट से जिसमें आप एजेंट को काम कराना चाहते हैं:

```bash
npx skills add wsj-br/ai-i18n-tools
```

यह कमांड `skills/` के तहत हर निर्देशिका को इंस्टॉल करता है, जिसमें साझा कौशल और प्रत्येक वर्कफ़्लो कमांड शामिल है। यह आपके प्रोजेक्ट में इस रिपॉजिटरी का चेकआउट नहीं छोड़ता है। डिफ़ॉल्ट स्कोप वर्तमान प्रोजेक्ट है। अपने उपयोगकर्ता के लिए, सभी प्रोजेक्ट्स में इंस्टॉल करने के लिए `-g` जोड़ें।

```bash
npx skills add wsj-br/ai-i18n-tools --all -y
npx skills add wsj-br/ai-i18n-tools --list
npx skills add wsj-br/ai-i18n-tools --skill ai-i18n-vitepress -a cursor
npx skills update
```

`--all -y` एक-चरणीय इंस्टाल है: हर कौशल, कोई प्रॉम्प्ट नहीं। `--all` के बिना, इंस्टालर पूछता है कि कौन से कौशल कॉपी करने हैं। `--list` कौशल को प्रिंट करता है और कुछ भी इंस्टॉल नहीं करता है। `--skill` और `-a` एक कौशल और एक एजेंट के लिए प्रॉम्प्ट छोड़ देते हैं। `npx skills update` इस तरह इंस्टॉल किए गए कौशल को रीफ़्रेश करता है। पहली इंस्टाल के बाद जोड़े गए कौशल को लेने के लिए `add` को फिर से चलाएँ।

कौशल को प्रॉम्प्ट के रूप में प्रिंट करने के लिए, या इसे इंस्टॉल किए बिना, इसके साथ एक समर्थित एजेंट लॉन्च करने के लिए:

```bash
npx skills use wsj-br/ai-i18n-tools@ai-i18n-tools
```

सीएलआई मशीन पर इंस्टॉल किए गए कोडिंग एजेंटों का पता लगाता है। प्रत्येक एजेंट के लिए इंस्टाल पाथ [स्किल्स सीएलआई एजेंट सूची](https://github.com/vercel-labs/skills/blob/main/docs/agents.md) में हैं। वह सूची बदलती रहती है। यह पृष्ठ इसे दोहराता नहीं है और यह दावा नहीं करता है कि हर कोडिंग टूल एक कौशल फ़ोल्डर पढ़ता है।

स्किल्स सीएलआई गुमनाम उपयोग डेटा एकत्र करता है। इसे बंद करने के लिए `DISABLE_TELEMETRY=1` या `DO_NOT_TRACK=1` सेट करें।

इंस्टॉल करने के बाद, यदि उस उत्पाद को रीलोड की आवश्यकता है तो एक नया एजेंट सत्र शुरू करें। `/ai-i18n-vitepress` जैसा एक वर्कफ़्लो कमांड टाइप करें, या एजेंट से `ai-i18n-tools` कौशल का उपयोग करने के लिए कहें। साझा कौशल उस अनुरोध के लिए फ़ॉलबैक है जो किसी कमांड का नाम नहीं लेता है। एक खोजा गया कौशल इस बात की गारंटी नहीं है कि एजेंट इसे अपने आप लागू करेगा।

<a id="slash-commands"></a>
## स्लैश कमांड

साझा `ai-i18n-tools` कौशल एजेंट के लिए उपलब्ध रहता है। अन्य कौशल स्पष्ट कमांड हैं। प्रत्येक साझा कौशल का पालन करता है, फिर केवल अपने टेम्पलेट और जांच को लागू करता है।

| कमांड | वर्कफ़्लो |
| --- | --- |
| `/ai-i18n-js` | जावास्क्रिप्ट या टाइपस्क्रिप्ट सोर्स-स्ट्रिंग यूआई |
| `/ai-i18n-python` | जनरेटेड पायथन हेल्पर और फ़्लैट JSON कैटलॉग |
| `/ai-i18n-django` | Django, Flask-Babel, या प्लेन गेटटेक्स्ट |
| `/ai-i18n-vitepress` | VitePress |
| `/ai-i18n-starlight` | Astro Starlight डॉक्स |
| `/ai-i18n-docusaurus` | Docusaurus |
| `/ai-i18n-nextra` | Nextra |
| `/ai-i18n-fumadocs` | Fumadocs |
| `/ai-i18n-astro-website` | वनीला एस्ट्रो वेबसाइट |
| `/ai-i18n-plain-html` | एक HTML फ़ाइल, ब्राउज़र में स्विच की गई |
| `/ai-i18n-plain-html-docs` | प्रति लोकले एक HTML ट्री |
| `/ai-i18n-readme` | रीडमी और रिपॉजिटरी मार्कडाउन |
| `/ai-i18n-migrate-intlayer` | इंटलेयर से `t()` कॉल में एक बार का स्थानांतरण |
| `/ai-i18n-translate-intlayer` | इंटलेयर डिक्शनरी यथास्थान भरें |

`.agents/skills/` या `.cursor/skills/` में कॉपी की गई स्किल्स इन कमांड के रूप में दिखाई देती हैं। कर्सर में एक मौजूदा बग मार्केटप्लेस-प्लगइन स्किल्स को छुपाता है जो `/` पैलेट से `disable-model-invocation` सेट करती हैं। क्लाउड कोड, कोडेक्स और कोपायलट अभी भी उन कमांड को दिखाते हैं। जब आप कर्सर में कमांड चाहते हैं तो स्किल्स सीएलआई इंस्टॉल का उपयोग करें। एक गद्य अनुरोध अभी भी साझा स्किल तक पहुँचता है।

<a id="download-the-skill-directory"></a>
## स्किल डायरेक्टरी डाउनलोड करें

इसका उपयोग तब करें जब स्किल्स सीएलआई उपलब्ध न हो। हर स्किल डायरेक्टरी को कॉपी करें, केवल `ai-i18n-tools/` को नहीं। प्रत्येक वर्कफ़्लो कमांड अपनी खुद की फ़ोल्डर है जिसमें एक `SKILL.md` है। एक स्किल पाथ का गिट क्लोन और `npx degit` दोनों रिपॉजिटरी स्रोत आर्काइव डाउनलोड करते हैं, लगभग 50 MB।

[स्किल्स सीएलआई एजेंट सूची](https://github.com/vercel-labs/skills/blob/main/docs/agents.md) से एक एजेंट डायरेक्टरी चुनें। नीचे दिए गए उदाहरण `.agents/skills/` का उपयोग करते हैं, जिसे कई एजेंट पढ़ते हैं। मौजूदा कॉपी को बदलने से पहले उस गंतव्य का निरीक्षण करें। प्रति एजेंट एक कॉपी पर्याप्त है। उसी एजेंट के लिए किसी अन्य डिस्कवरी फ़ोल्डर में एक दूसरी कॉपी एक डुप्लीकेट है।

एनपीएम पैकेज में पहले से ही डायरेक्टरी शामिल हैं। जब पैकेज इंस्टॉल हो जाता है:

```bash
mkdir -p .agents/skills
cp -a node_modules/ai-i18n-tools/skills/. .agents/skills/
```

बिना `node_modules` के, उसी वर्ज़न के लिए एनपीएम टारबॉल डाउनलोड करें जिसकी सीएलआई रिपोर्ट करती है। `ai-i18n-tools --version` वर्ज़न प्रिंट करता है, फिर बिल्ड टाइमस्टैम्प। केवल वर्ज़न नंबर का उपयोग करें। टारबॉल मेंबर `package/skills/` है।

```bash
mkdir -p .agents/skills
curl -fsSL https://registry.npmjs.org/ai-i18n-tools/-/ai-i18n-tools-1.12.0.tgz \
  | tar -xz --strip-components=2 -C .agents/skills package/skills
```

`1.12.0` को आपके द्वारा इंस्टॉल किए गए वर्ज़न से बदलें। यह मौजूदा रिलीज़ के लिए काम करता है। स्टैंडअलोन एक्सेक्यूटेबल में स्किल फ़ाइलें शामिल नहीं हैं। टारबॉल का मिलान `ai-i18n-tools --version` से करें।

इसे जोड़ने वाली रिलीज़ से, गिटहब रिलीज़ भी `ai-i18n-tools-skill.zip` संलग्न करती हैं। उस ज़िप में उसके शीर्ष स्तर पर हर स्किल डायरेक्टरी शामिल है। इसे एजेंट स्किल्स फ़ोल्डर में अनपैक करें ताकि परिणाम में `ai-i18n-tools/SKILL.md` और वर्कफ़्लो फ़ोल्डर दोनों शामिल हों, जैसे `ai-i18n-vitepress/SKILL.md`। उस ज़िप से पहले प्रकाशित रिलीज़ इसे शामिल नहीं करती हैं। पुरानी ज़िप फ़ाइलों में केवल `ai-i18n-tools/` शामिल है। उन रिलीज़ के लिए एनपीएम टारबॉल का उपयोग करें। टैग `v` और सीएलआई वर्ज़न है, उदाहरण के लिए `v1.12.0` एक बार जब उस टैग की रिलीज़ में एसेट हो।

<a id="agents-the-skills-cli-installs"></a>
## एजेंट जिन्हें स्किल्स सीएलआई इंस्टॉल करती है

जब आप एक एजेंट चाहते हैं तो आईडी को `-a` को पास करें। इन टूल के लिए इस रिपॉजिटरी में और कुछ भी आवश्यक नहीं है।

सीएलआई एजेंट: क्लाउड कोड (`claude-code`), कोडेक्स सीएलआई (`codex`), जेमिनी सीएलआई (`gemini-cli`), एंटीग्रेविटी सीएलआई (`antigravity-cli`), गिटहब कोपायलट सीएलआई (`github-copilot`), ओपनकोड (`opencode`), गूज़ (`goose`), क्वेन कोड (`qwen-code`), किलो सीएलआई (`kilo`), ग्रोक बिल्ड (`grok`), एम्प (`amp`), क्रश (`crush`), पाई (`pi`), किरो सीएलआई (`kiro-cli`)।

एडिटर और आईडीई: कर्सर (`cursor`), विंडसर्फ (`windsurf`), डेविन फॉर टर्मिनल (`devin`), ज़ेड (`zed`), एंटीग्रेविटी (`antigravity`), ट्रे (`trae`), जूनी (`junie`), रेप्लिट (`replit`), क्लाइन (`cline`), रू कोड (`roo`), किलो कोड (`kilo`), कंटिन्यू (`continue`), ऑगमेंट (`augment`), फैक्ट्री ड्रॉइड (`droid`), टैबनाइन सीएलआई (`tabnine-cli`)। एक एडिटर में गिटहब कोपायलट वही `github-copilot` आईडी का उपयोग करता है जो सीएलआई करती है।

दो पाथ विवरण जिन्हें नज़रअंदाज़ करना आसान है:

- Cursor: स्किल्स CLI से प्रोजेक्ट इंस्टॉल `.agents/skills/` पर जाता है। `-g` `~/.cursor/skills/` पर जाता है। Cursor के अपने डॉक्स भी एक प्रोजेक्ट में `.cursor/skills/` को स्वीकार करते हैं। इनमें से किसी एक का उपयोग करें।
- GitHub Copilot: स्किल्स CLI प्रोजेक्ट में `.agents/skills/` और `-g` के लिए `~/.copilot/skills/` लिखता है। GitHub के क्लाउड-एजेंट डॉक्स भी `.github/skills/` का वर्णन करते हैं। वह फ़ोल्डर हर Copilot चैट द्वारा नहीं पढ़ा जाता है। आप जिस सतह का उपयोग करते हैं, उसके लिए दस्तावेज़ित फ़ोल्डर का ही उपयोग करें।

Kiro CLI का डिफ़ॉल्ट एजेंट बिना किसी अतिरिक्त कॉन्फ़िगरेशन के `.kiro/skills/` और `~/.kiro/skills/` को लोड करता है। एक कस्टम Kiro एजेंट को `.kiro/agents/<agent>.json` में सूचीबद्ध इंस्टॉल किए गए स्किल्स की आवश्यकता होती है:

```json
{
  "resources": ["skill://.kiro/skills/**/SKILL.md"]
}
```

<a id="native-catalogs"></a>
## नेटिव कैटलॉग

कुछ उत्पाद इस रिपॉजिटरी में एक कैटलॉग से स्किल्स भी इंस्टॉल करते हैं। प्रत्येक एजेंट के लिए एक चैनल का उपयोग करें: कैटलॉग या स्किल्स CLI। एक पैकेज अपग्रेड हाथ से कॉपी की गई स्किल को रीफ़्रेश नहीं करता है। `npx skills update` एक स्किल्स CLI इंस्टॉल को रीफ़्रेश करता है। कैटलॉग इंस्टॉल उस उत्पाद के अपडेट कमांड का पालन करते हैं।

- Cursor Marketplace, लिस्टिंग स्वीकृत होने के बाद: Cursor Marketplace से `ai-i18n-tools` इंस्टॉल करें। जब तक वह लिस्टिंग मौजूद नहीं है, तब तक स्किल्स CLI का उपयोग करें। [Cursor Directory](https://cursor.directory) एक अलग सामुदायिक लिस्टिंग है।
- Claude Code, एक Claude Code सत्र से:

```text
/plugin marketplace add wsj-br/ai-i18n-tools
/plugin install ai-i18n-tools@ai-i18n-tools
```

- GitHub Copilot CLI:

```bash
copilot plugin marketplace add wsj-br/ai-i18n-tools
```

फिर उस मार्केटप्लेस से `ai-i18n-tools` प्लगइन इंस्टॉल करें। प्लगइन आईडी `ai-i18n-tools@ai-i18n-tools` है। Copilot CLI वही कैटलॉग फ़ाइल पढ़ता है जिसका उपयोग Claude Code करता है।

- Codex:

```bash
codex plugin marketplace add wsj-br/ai-i18n-tools
```

एक ChatGPT वर्कस्पेस लिस्टिंग को वर्कस्पेस एडमिन द्वारा अलग से प्रकाशित किया जाता है। यह इस कमांड से एक अलग इंस्टॉल है।

## स्किल्स इंस्टॉल के बिना एजेंट

ये उत्पाद स्किल्स CLI एजेंट सूची में नहीं हैं। यह रिपॉजिटरी उनके लिए एक अलग स्किल फ़ोल्डर शिप नहीं करती है। एजेंट को प्रोजेक्ट निर्देशों जैसे `AGENTS.md` से [कंज्यूमर कॉन्टेक्स्ट](https://github.com/wsj-br/ai-i18n-tools/blob/main/docs/ai-i18n-tools-context.md) पर इंगित करें:

```markdown
Before installing or maintaining ai-i18n-tools, read
https://github.com/wsj-br/ai-i18n-tools/blob/main/docs/ai-i18n-tools-context.md
and follow only the linked reference that matches this project.
Use ai-i18n-tools sync for the configured workflow.
```

वह फ़ाइल डॉक्यूमेंटेशन-साइट और रिपॉजिटरी URL का उपयोग करती है, इसलिए एजेंट इस रिपॉजिटरी को नहीं पढ़ पाने पर भी निर्देश काम करता है। पुराने CLI के लिए, मिलान करने वाले रिलीज़ टैग पर वही पाथ खोलें। कंज्यूमर प्रोजेक्ट इस कॉन्टेक्स्ट फ़ाइल का उपयोग करते हैं। इस रिपॉजिटरी को बदलते समय मेंटेनर `AGENTS.md` लागू होता है।

इस समूह के उत्पाद: Aider, gptme, Amazon Q Developer CLI, DeepSeek Harness, JetBrains AI Assistant, Sourcegraph Cody, Qodo, the Tabnine IDE plugin, CodeGeeX, और AskCodi। Junie वह JetBrains एजेंट है जो स्किल्स CLI इंस्टॉल लेता है। Tabnine CLI भी लेता है। AiderDesk, Aider से एक अलग एप्लिकेशन है।

CodeLayer और Superset का अपना कोई स्किल डायरेक्टरी नहीं है। CodeLayer Claude Code चलाता है, इसलिए Claude Code के लिए स्किल इंस्टॉल करें। Superset आपके द्वारा कॉन्फ़िगर किए गए CLI एजेंटों को चलाता है, इसलिए उन एजेंटों के लिए स्किल इंस्टॉल करें।

## एक ही संस्करण पर बने रहें

स्किल को `ai-i18n-tools` कमांड के समान रिलीज़ पर रखें। एक npm अपग्रेड, और एक नया स्टैंडअलोन एक्सेक्यूटेबल, हाथ से कॉपी की गई स्किल को वहीं छोड़ देते हैं जहाँ वह थी। मिलान करने वाले संस्करण से स्किल को फिर से इंस्टॉल करें, या स्किल्स CLI इंस्टॉल के लिए `npx skills update` चलाएँ।

ऑनलाइन डॉक्यूमेंटेशन आपके द्वारा इंस्टॉल किए गए कमांड से एक नए रिलीज़ का वर्णन कर सकता है। फ़्लैग के लिए `ai-i18n-tools --help` को प्राथमिकता दें। आगे के संदर्भ के लिए: [इंस्टॉलेशन](/hi/guide/installation), [कॉन्फ़िगरेशन](/hi/reference/configuration), [प्रोवाइडर](/hi/guide/providers-and-models), [CLI संदर्भ](/hi/reference/cli-commands/)।
