# HTML पृष्ठ

`translate-docs` प्रत्येक लोकेल के लिए एक HTML फ़ाइल उत्पन्न कर सकता है। `.html` या `.htm` फ़ाइलों को `docs[]` `contentPaths` प्रविष्टि पर रखें और `translate-docs` या `sync` चलाएँ। अंग्रेज़ी फ़ाइल स्रोत के रूप में रहती है। लोकेल प्रतियाँ `outputDir` के अंतर्गत लिखी जाती हैं।

इसका उपयोग तब करें जब प्रत्येक भाषा का अपना अलग पृष्ठ हो (एक स्थैतिक साइट, हाथ से लिखे गए HTML दस्तावेज़ों का एक सेट)। [साधारण HTML ऐप्स](/hi/guide/ui-strings/plain-html) का उपयोग तब करें जब एक HTML फ़ाइल अपनी जगह पर रहती है और ब्राउज़र फ्लैट JSON से स्ट्रिंग्स को बदलता है।

इसके साथ स्कैफोल्ड करें:

```bash
ai-i18n-tools init -t docs-plain-html [-P <provider>]
```

चलाने योग्य डेमो [`examples/plain-html-docs`](https://github.com/wsj-br/ai-i18n-tools/tree/main/examples/plain-html-docs) (पोर्ट 3092) है।

<a id="what-is-translated"></a>
## क्या अनुवादित होता है

अनुवादित: दृश्यमान टेक्स्ट, `alt`, `title`, `aria-label`, `placeholder`, `<title>`, `meta name="description"`, और `og:title` / `og:description`।

अपरिवर्तित छोड़े गए: `script`, `style`, `textarea`, `pre`, और `code` तत्व, साथ ही `src`, `href`, और अन्य URL। एक पैराग्राफ जिसमें `<code>` या `<em>` होता है, उन टैग्स को बनाए रखता है और आस-पास के शब्दों का अनुवाद करता है।

`html lang` और `dir` लोकेल फ़ाइल पर सेट किए जाते हैं। अंग्रेज़ी स्रोत अपना `lang` तब तक बनाए रखता है जब तक आप इसे बदलते नहीं हैं।

उत्पन्न की गई लोकेल फ़ाइलें अगले रन पर छोड़ दी जाती हैं जब वे `outputDir` (एक `pt-BR/` निर्देशिका, या एक फ्लैट `name.pt-BR.html`) के अंतर्गत होती हैं। एक चेतावनी प्रिंट की जाती है जब वही `.html` फ़ाइल UI कैटलॉग स्रोत (`ui.sourceRoots`) भी होती है।

<a id="links-and-images"></a>
## लिंक और छवियाँ

समान `docs[]` ब्लॉक में अन्य HTML पृष्ठों के लिंक उस पृष्ठ के लोकेल आउटपुट के लिए पुनर्लेखित किए जाते हैं। अन्य सापेक्ष URL में उपसर्ग जोड़े जाते हैं ताकि वे लोकेल फ़ाइल से अभी भी हल हो सकें।

`docsOutput.localizedAssets` वैकल्पिक रूप से छवियों और आइकनों का नाम बदल देता है जब एक लोकेल-विशिष्ट फ़ाइल मौजूद होती है। CSS `url()` को पुनर्लेखित नहीं किया जाता है।

```json
"localizedAssets": {
  "include": ["img/**"],
  "pattern": "{stem}-{locale}{ext}",
  "onlyIfExists": true
}
```

| प्लेसहोल्डर | अर्थ |
| --- | --- |
| `{stem}` | एक्सटेंशन के बिना फ़ाइलनाम |
| `{ext}` | एक्सटेंशन, डॉट सहित |
| `{basename}` | एक्सटेंशन के साथ फ़ाइलनाम |
| `{locale}` | कॉन्फ़िगर किए गए अनुसार लोकेल कोड (`pt-BR`) |
| `{llocale}` | लोअरकेस लोकेल |
| `{LOCALE}` | अपरकेस लोकेल |

उपरोक्त पैटर्न के साथ `img/trulli.jpg`, `img/trulli-pt-BR.jpg` बन जाता है। `onlyIfExists: true` (डिफ़ॉल्ट) के साथ, मूल URL को तब तक रखा जाता है जब वह फ़ाइल मौजूद न हो। निरपेक्ष URL, `data:` URL, और `#` फ्रैगमेंट्स को छोड़ दिया जाता है। रूट-सापेक्ष URL (`/img/trulli.jpg`) को `assetRoot` के अंतर्गत परखा जाता है, या जब `assetRoot` को छोड़ दिया जाता है तो HTML फ़ाइल की निर्देशिका के अंतर्गत।

`srcset`, `poster`, `<source src>`, आइकन `<link>` URLs, और `og:image` / `twitter:image` समान नियमों का उपयोग करते हैं।

HTML के लिए, लोकैल फ़ोल्डर जोड़े जाने से पहले प्रोजेक्ट-सापेक्ष पथ से `docsOutput.docsRoot` हटा दिया जाता है। `docsRoot: "site"` और `style: "nested"` के साथ, `site/index.html` को `site/pt-BR/index.html` में लिखा जाता है।

<a id="language-list-and-hreflang"></a>
## भाषा सूची और hreflang

प्रत्येक लोकैल कॉपी और अंग्रेज़ी स्रोत पर दो टिप्पणी युग्म भरे जाते हैं (ताकि वैकल्पिक लिंक पारस्परिक बने रहें):

```html
<nav>
  <ul>
    <!-- ai-i18n:lang-list -->
    <!-- /ai-i18n:lang-list -->
  </ul>
</nav>
<!-- ai-i18n:hreflang -->
<!-- /ai-i18n:hreflang -->
```

`script`, `style`, `pre`, और `code` के अंदर के मार्कर अनदेखे कर दिए जाते हैं। जब किसी पेज पर कोई युग्म नहीं होता है, तो एक वर्बोज़ रन चेतावनी देता है। जब `docsOutput.html` को छोड़ दिया जाता है, तो वही टिप्पणियाँ डिफ़ॉल्ट होती हैं।

```json
"html": {
  "languageList": {
    "format": "links",
    "label": "local",
    "separator": " · "
  },
  "hreflang": {
    "siteUrl": "https://example.com",
    "xDefault": "en",
    "stripIndexHtml": true
  }
}
```

`format: "links"` `<a>` तत्व लिखता है। `<ul>`, `<ol>`, या `<nav>` के अंदर प्रत्येक लिंक `<li>` में रैप किया जाता है। `format: "select"` `<option>` पंक्तियाँ लिखता है। मार्कर को अपने स्वयं के `<select data-lang-select>` के अंदर रखें और `lang-select.js` लोड करें (जो `ai-i18n-tools/html-runtime/lang-select.js` के रूप में शिप किया जाता है, और उदाहरण में कॉपी किया जाता है)। एक ब्लॉक एक प्रारूप का उपयोग करता है।

`label` `local` (एंडोनिम), `english`, या `both` (`English / endonym` जब वे भिन्न हों) है। वे लोकैल जो कॉन्फ़िगर किए गए सेट में नहीं हैं, उन्हें छोड़ दिया जाता है।

`hreflang.siteUrl` वैकल्पिक लिंक में प्रीफ़िक्स जोड़ता है। जब यह अनसेट होता है, तो लिंक सापेक्ष होते हैं और एक चेतावनी लॉग की जाती है। `xDefault` डिफ़ॉल्ट रूप से `sourceLocale` होता है। `stripIndexHtml` `index.html` को एक डायरेक्टरी URL में बदल देता है।

कोई साइटमैप फ़ाइल नहीं है, कोई स्वचालित `<head>` इंजेक्शन नहीं है, और कोई `canonical` या `og:locale` रिराइट नहीं है। ब्राउज़र भाषा विज़िटर को रीडायरेक्ट नहीं करती है।

<a id="second-run"></a>
## दूसरा रन

वाक्य अनुवाद कैश में रहते हैं। फ़ाइल-ट्रैकिंग हैश में लोकैल सूची और `docsOutput.html` / `localizedAssets` भी शामिल होते हैं। किसी लोकैल को जोड़ने से भाषा सूची और hreflang ब्लॉक फिर से लिखे जाते हैं, भले ही प्रत्येक वाक्य पहले से ही कैश किया गया हो। मेल खाते हुए हैश और अद्यतित आउटपुट फ़ाइल होने पर पेज को स्किप कर दिया जाता है।
