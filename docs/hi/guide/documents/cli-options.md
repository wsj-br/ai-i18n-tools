# CLI विकल्प

`translate-docs` कैश व्यवहार, फ़्लैग, बैच प्रॉम्प्ट फ़ॉर्मेट और आंतरिक SQLite पाथ कुंजियों के लिए संदर्भ।

<a id="cache-behaviour-and-translate-docs-flags"></a>
## कैश व्यवहार और `translate-docs` फ़्लैग

CLI SQLite में **फ़ाइल ट्रैकिंग** (प्रति फ़ाइल × लोकेल स्रोत हैश) और **सेगमेंट** पंक्तियाँ (प्रति अनुवाद योग्य खंड हैश × लोकेल) रखता है। एक सामान्य रन किसी फ़ाइल को पूरी तरह से छोड़ देता है जब ट्रैक किया गया हैश वर्तमान स्रोत से मेल खाता है, आउटपुट फ़ाइल पहले से मौजूद है, **और** आउटपुट का संशोधन समय स्रोत के जितना नया है; अन्यथा यह फ़ाइल को संसाधित करता है और सेगमेंट कैश का उपयोग करता है ताकि अपरिवर्तित टेक्स्ट API को कॉल न करे।

| फ़्लैग | प्रभाव |
|-------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| *(डिफ़ॉल्ट)* | ट्रैकिंग + ऑन-डिस्क आउटपुट मेल खाने पर अपरिवर्तित फ़ाइलों को छोड़ दें; बाकी के लिए सेगमेंट कैश का उपयोग करें। |
| `-l, --locale <codes>` | कॉमा-सेपरेटेड टारगेट लोकेल (जब छोड़ा जाता है, तो डिफ़ॉल्ट रूट `targetLocales` और प्रत्येक `docs[]` ब्लॉक के वैकल्पिक `targetLocales` के संघ से मेल खाते हैं)। |
| `-p, --path` / `-f, --file` | केवल इस पाथ के तहत मार्कडाउन/JSON का अनुवाद करें (प्रोजेक्ट-सापेक्ष, निरपेक्ष, या ग्लोब पैटर्न); `--file` `--path` के लिए एक उपनाम है। |
| `--dry-run` | कोई फ़ाइल राइट्स नहीं और कोई एपीआई कॉल नहीं। |
| `--type <kind>` | `markdown` या `json` तक सीमित करें (अन्यथा कॉन्फ़िग में सक्षम होने पर दोनों)। |
| `--json-only` / `--no-json` | केवल JSON लेबल फ़ाइलों का अनुवाद करें, या JSON को छोड़ दें और केवल मार्कडाउन का अनुवाद करें। |
| `-j, --concurrency <n>` | अधिकतम समानांतर टारगेट लोकेल (कॉन्फ़िग या CLI बिल्ट-इन डिफ़ॉल्ट से डिफ़ॉल्ट)। |
| `-b, --batch-concurrency <n>` | प्रति फ़ाइल अधिकतम समानांतर बैच API कॉल (डॉक्स; कॉन्फ़िग या CLI से डिफ़ॉल्ट)। |
| `--emphasis-placeholders` | अनुवाद से पहले मार्कडाउन एम्फेसिस मार्कर को प्लेसहोल्डर के रूप में मास्क करें। CJK और RTL लोकेल के लिए स्वतः सक्षम जब तक कि `docs[].emphasisPlaceholders` के माध्यम से प्रति ब्लॉक ओवरराइड न किया जाए या `--no-emphasis-placeholders` के साथ अक्षम न किया जाए। |
| `--debug-failed` | सत्यापन विफल होने पर `cacheDir` के तहत विस्तृत `FAILED-TRANSLATION` लॉग लिखें। |
| `--force-update` | हर मिलान की गई फ़ाइल को फिर से प्रोसेस करें (निकालें, फिर से जोड़ें, आउटपुट लिखें) भले ही फ़ाइल ट्रैकिंग छोड़ दे। **सेगमेंट कैश अभी भी लागू होता है** — अपरिवर्तित सेगमेंट LLM को नहीं भेजे जाते हैं। |
| `--force` | प्रत्येक प्रोसेस की गई फ़ाइल के लिए फ़ाइल ट्रैकिंग साफ़ करता है और API अनुवाद (पूर्ण पुनः-अनुवाद) के लिए सेगमेंट कैश **नहीं पढ़ता है**। नए परिणाम अभी भी सेगमेंट कैश में **लिखे जाते हैं**। |
| `--stats` | सेगमेंट की संख्या, ट्रैक की गई फ़ाइल की संख्या और प्रति-स्थानिक सेगमेंट कुल प्रिंट करें, फिर बाहर निकलें। |
| `--clear-cache [locale]` | कैश्ड अनुवाद (और फ़ाइल ट्रैकिंग) हटाएँ: सभी स्थानीय, या एक एकल स्थानीय, फिर बाहर निकलें। |
| `--prompt-format <mode>` | सेगमेंट के प्रत्येक **बैच** को मॉडल में कैसे भेजा जाता है और पार्स किया जाता है (`xml`, `json-array`, या `json-object`)। डिफ़ॉल्ट `json-array`। निष्कर्षण, प्लेसहोल्डर, सत्यापन, कैश, या फ़ॉलबैक व्यवहार को नहीं बदलता है — [बैच प्रॉम्प्ट प्रारूप](#batch-prompt-format) देखें। |

आप `--force` को `--force-update` के साथ नहीं जोड़ सकते (वे परस्पर अनन्य हैं)।

<a id="batch-prompt-format"></a>
## बैच प्रॉम्प्ट प्रारूप

`translate-docs` सक्रिय LLM प्रदाता को **बैचों** में अनुवाद योग्य सेगमेंट भेजता है (`batchSize` / `maxBatchChars` द्वारा समूहीकृत)। `--prompt-format` फ़्लैग केवल उस बैच के **वायर फ़ॉर्मेट** को बदलता है; `PlaceholderHandler` टोकन, मार्कडाउन AST चेक, SQLite कैश कुंजियाँ, और बैच पार्सिंग विफल होने पर प्रति-सेगमेंट फ़ॉलबैक अपरिवर्तित रहते हैं।

| मोड | उपयोगकर्ता संदेश | मॉडल उत्तर |
|---|---|---|
| `xml` | स्यूडो-XML: प्रति सेगमेंट एक `<seg id="N">…</seg>` (XML एस्केपिंग के साथ)। | केवल `<t id="N">…</t>` ब्लॉक, प्रति सेगमेंट इंडेक्स एक। |
| `json-array` (डिफ़ॉल्ट) | स्ट्रिंग्स का एक JSON सरणी, क्रम में प्रति सेगमेंट एक प्रविष्टि। | **समान लंबाई** (समान क्रम) का एक JSON सरणी। |
| `json-object` | सेगमेंट इंडेक्स द्वारा कुंजीबद्ध एक JSON ऑब्जेक्ट `{"0":"…","1":"…",…}`। | **समान कुंजियों** और अनुवादित मानों के साथ एक JSON ऑब्जेक्ट। |

कुछ मॉडल एक प्रारूप का दूसरे की तुलना में अधिक मज़बूती से पालन करते हैं, इसलिए यदि कोई मॉडल अक्सर गलत तरीके से स्वरूपित बैच या बेमेल सेगमेंट आईडी लौटाता है तो एक अलग मोड आज़माएँ। `json-array` डिफ़ॉल्ट है क्योंकि यह एक सामान्य, सरल प्रारूप है जिसे मॉडल आमतौर पर अच्छी तरह से संभालते हैं।

रन हेडर `Batch prompt format: …` भी प्रिंट करता है ताकि आप सक्रिय मोड की पुष्टि कर सकें। JSON लेबल फ़ाइलें (`docusaurusCatalogDir`) और SVG फ़ाइल बैच उसी सेटिंग का उपयोग करते हैं जब वे चरण `translate-docs` (या `sync` के डॉक्स चरण — `sync` इस फ़्लैग को उजागर नहीं करता है; यह `json-array` पर डिफ़ॉल्ट होता है) के हिस्से के रूप में चलते हैं।
