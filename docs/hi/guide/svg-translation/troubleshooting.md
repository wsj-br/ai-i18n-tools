# SVG समस्या निवारण

यह भी देखें [छवियाँ और स्क्रीनशॉट समस्या निवारण](/hi/guide/images-and-screenshots/troubleshooting)।

- **एक ही डायरेक्टरी में SVG स्रोत और आउटपुट** — `svg.sourcePath` और `svg.outputDir` को अलग रखें।
- **कोलोकेटेड SVG के लिए निरपेक्ष Docusaurus स्थिर URL** — शुरुआत से सापेक्ष `../assets/` पाथ का उपयोग करें।
