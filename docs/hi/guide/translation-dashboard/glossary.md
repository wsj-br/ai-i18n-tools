# शब्दावली

**शब्दावली** टैब आपकी उपयोगकर्ता शब्दावली CSV (कॉन्फ़िग में `glossary.userGlossary`) को संपादित करता है। यहाँ की प्रविष्टियाँ `translate-ui` और `proofread-ui` के लिए शब्दावली संकेत हैं — उनका उपयोग दस्तावेज़ अनुवाद द्वारा **नहीं** किया जाता है।

जब `glossary.userGlossary` कॉन्फ़िगर नहीं होता है तो टैब छिपा होता है।

<a id="csv-columns"></a>
## CSV कॉलम

| कॉलम | अर्थ |
| --- | --- |
| **मूल भाषा स्ट्रिंग** | स्रोत शब्द या वाक्यांश |
| **स्थान** | लक्ष्य स्थान, या सभी स्थानों के लिए `*` |
| **अनुवाद** | पसंदीदा अनुवाद |
| **बलपूर्वक** | जब चेक किया जाता है, तो शब्द का अनुवाद बिल्कुल दिए गए अनुसार ही किया जाना चाहिए |

<a id="add-a-row"></a>
## एक पंक्ति जोड़ें

टैब के शीर्ष पर दिए गए फ़ॉर्म का उपयोग करें:

1. **मूल**, **स्थान** (`*` या एक लक्ष्य स्थान कोड), और **अनुवाद** दर्ज करें।
2. वैकल्पिक रूप से **बलपूर्वक** चेक करें।
3. **जोड़ें** पर क्लिक करें।

यदि CSV फ़ाइल अभी तक मौजूद नहीं है तो पहली बार जोड़ने पर बनाई जाती है।

<a id="edit-or-delete"></a>
## संपादित करें या हटाएँ

- **इनलाइन संपादित करें** — तालिका में सीधे फ़ील्ड बदलें और उस पंक्ति पर **सहेजें** पर क्लिक करें।
- **हटाएँ** — हटाएँ नियंत्रण के साथ एक पंक्ति हटाएँ।

परिवर्तन अगले `translate-ui`, `proofread-ui`, या `sync` UI चरण पर प्रभावी होते हैं।

<a id="filters"></a>
## फ़िल्टर

**मूल पाठ**, **स्थान** (`*` सहित), या **अनुवाद पाठ** उपस्ट्रिंग द्वारा फ़िल्टर करें, फिर **लागू करें** पर क्लिक करें।

<a id="dashboard-edits-and-glossary-auto-add"></a>
## डैशबोर्ड संपादन और शब्दावली स्वतः-जोड़

जब आप **UI स्ट्रिंग्स** या **UI बहुवचन** टैब में एक UI स्ट्रिंग को ठीक करते हैं, तो अगला `translate-ui` रन उस सुधार को शब्दावली में स्वचालित रूप से जोड़ सकता है यदि `glossary.autoAddUserEditedToGlossary` `true` है। उन स्वतः-जोड़ी गई पंक्तियों की समीक्षा करने, समायोजित करने या हटाने के लिए शब्दावली टैब का उपयोग करें।
