# अनुवाद डैशबोर्ड

अनुवाद डैशबोर्ड आपके प्रोजेक्ट के अनुवाद डेटा का निरीक्षण और संपादन करने के लिए एक स्थानीय वेब UI है। यह तीन स्टोर से पढ़ता है:

- **SQLite कैश** (`cacheDir`) — दस्तावेज़ खंड अनुवाद, विफलता रिकॉर्ड, मार्कडाउन समस्या स्कैन
- **`strings.json`** — UI स्ट्रिंग कैटलॉग (सादे स्ट्रिंग और बहुवचन समूह)
- **उपयोगकर्ता शब्दावली CSV** (`glossary.userGlossary`) — `translate-ui` और `proofread-ui` के लिए शब्दावली संकेत

समस्याओं को खोजने, खराब आउटपुट को ओवरराइड करने, या कैश कवरेज की समीक्षा करने के लिए अनुवाद चलाने के बाद इसका उपयोग करें — बिना SQLite या JSON को हाथ से खोदे।

<a id="start-the-dashboard"></a>
## डैशबोर्ड शुरू करें

```bash
ai-i18n-tools dashboard
# Optional: choose port, do not auto-open browser
# ai-i18n-tools dashboard -p 8765 --no-open
```

डिफ़ॉल्ट लिसन पोर्ट **8675** है। यदि वह पोर्ट अनुपलब्ध है, तो सर्वर अगले पोर्ट (1000 प्रयासों तक) का प्रयास करता है और उसके द्वारा चुने गए पोर्ट को लॉग करता है। बहिष्कृत उपनाम `editor` अभी भी काम करता है लेकिन एक चेतावनी प्रिंट करता है — `dashboard` को प्राथमिकता दें।

डैशबोर्ड UI CLI के समान लोकेल रिज़ॉल्यूशन का उपयोग करता है: `-L` / `--ui-lang` → `AI_I18N_LANG` → कॉन्फ़िग `uiLanguage` → OS लोकेल। [टूल UI भाषा](/hi/guide/tool-ui-language) देखें।

<a id="after-you-edit"></a>
## संपादन के बाद

| आपने संपादित किया… | फिर चलाएँ… | बचें… |
| --- | --- | --- |
| दस्तावेज़ कैश पंक्ति | `sync --force-update` या `translate-docs --force-update` | — |
| UI स्ट्रिंग या बहुवचन | सादा `sync` या `translate-ui` | `--force` (`user-edited` पंक्तियों को अधिलेखित करता है) |
| शब्दावली पंक्ति | अगला `translate-ui` या `proofread-ui` | — |

**दस्तावेज़ीकरण (SQLite कैश)** — मैन्युअल संपादन को कैश में मॉडल `user-edited` के साथ टैग किया जाता है। अपरिवर्तित स्रोत पर `translate-docs` या `sync` को फिर से चलाने से कैश किए गए अनुवाद का पुन: उपयोग होता है (कोई LLM कॉल नहीं)। कैश से ऑन-डिस्क मार्कडाउन को ताज़ा करने के लिए `sync --force-update` या `translate-docs --force-update` चलाएँ। `--force` का उपयोग केवल तभी करें जब आप कैश को बायपास करना चाहते हैं और LLM से फिर से अनुवाद करना चाहते हैं (मैन्युअल सुधारों को अधिलेखित करते हुए)।

**UI स्ट्रिंग्स (`strings.json`)** — मैन्युअल संपादन को `models[locale]` में `user-edited` के साथ टैग किया जाता है। `translate-ui` या `sync` को फिर से चलाने से उन प्रविष्टियों को छोड़ दिया जाता है जिनका पहले से ही अनुवाद है। मैन्युअल सुधारों को फिर से अनुवादित करने और अधिलेखित करने के लिए UI कमांड पर `--force` का उपयोग करें।

<a id="tips"></a>
## युक्तियाँ

- **लॉग-लिंक बटन** (तालिका पंक्तियों में 🔗) **टर्मिनल** पर फ़ाइल:लाइन संकेत प्रिंट करते हैं जहाँ `ai-i18n-tools dashboard` चल रहा है — ब्राउज़र से अपने संपादक पर जाने के लिए उपयोगी। यदि आप VS कोड व्युत्पन्न IDE (जैसे कर्सर, एंटीग्रेविटी, ...) का उपयोग कर रहे हैं, तो आप इंगित लाइन पर फ़ाइल खोलने के लिए टर्मिनल विंडो में फ़ाइल:लाइन लिंक पर `CTRL`-क्लिक कर सकते हैं।
- **बंद करें** (टैब बार के ऊपर-दाएँ) डैशबोर्ड सर्वर को ठीक से बंद कर देता है।
- यदि ब्राउज़र टैब अभी भी खुला होने पर सर्वर बंद हो जाता है, तो एक ओवरले दिखाई देता है। फिर से कनेक्ट करने के लिए `ai-i18n-tools dashboard` को पुनरारंभ करें, या यदि आप डैशबोर्ड के साथ काम कर चुके हैं तो विंडो बंद कर दें।
