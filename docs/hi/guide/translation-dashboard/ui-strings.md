# UI स्ट्रिंग और बहुवचन

**UI स्ट्रिंग** और **UI बहुवचन** टैब आपके `strings.json` कैटलॉग में पंक्तियों को संपादित करते हैं। डैशबोर्ड परिवर्तन सीधे उस फ़ाइल में लिखते हैं — SQLite दस्तावेज़ कैश में नहीं।

जब `translate-ui` या `sync` के बाद UI लेबल या बहुवचन रूप को मैन्युअल सुधार की आवश्यकता हो तो इन टैब का उपयोग करें।

<a id="ui-strings-tab"></a>
## UI स्ट्रिंग टैब

`strings.json` से गैर-बहुवचन प्रविष्टियों को सूचीबद्ध करता है — प्रति स्ट्रिंग आईडी और लोकेल एक पंक्ति।

<a id="filters"></a>
### फ़िल्टर

| फ़िल्टर | उद्देश्य |
| --- | --- |
| **आईडी / हैश** | स्ट्रिंग आईडी या हैश |
| **फ़ाइल नाम (आंशिक)** / **फ़ाइलपाथ चुनें** | स्रोत फ़ाइल स्कोप |
| **स्रोत में शामिल है** / **अनुवादित में शामिल है** | टेक्स्ट सबस्ट्रिंग |
| **लोकेल** | एकल लोकेल या सभी |
| **मॉडल** | अनुवाद उत्पन्न करने वाला मॉडल |

<a id="edit"></a>
### संपादित करें

1. किसी पंक्ति पर संपादन आइकन पर क्लिक करें।
2. अनुवादित टेक्स्ट बदलें और सहेजें।

प्रविष्टि का `models[locale]` `user-edited` पर सेट है। फ़्लैट लोकेल फ़ाइलों (`de.json`, आदि) को रीफ़्रेश करने के लिए सादा `sync` या `translate-ui` चलाएँ। `--force` का उपयोग **न करें** — यह प्रत्येक प्रविष्टि का पुनः अनुवाद करता है और मैन्युअल सुधारों को अधिलेखित कर सकता है।

जब `glossary.autoAddUserEditedToGlossary` `true` (डिफ़ॉल्ट) होता है, तो अगला `translate-ui` या `sync` आपके संपादन को उपयोगकर्ता शब्दावली CSV में स्वचालित रूप से जोड़ सकता है — [कॉन्फ़िगरेशन](/hi/reference/configuration#glossary) देखें।

<a id="delete"></a>
### हटाएँ

- **पंक्ति हटाएँ आइकन** — एक प्रविष्टि से एक लोकेल बकेट हटाता है।
- **फ़िल्टर किया गया हटाएँ** — वर्तमान फ़िल्टर से मेल खाने वाले सभी लोकेल बकेट को थोक में हटाएँ।

<a id="log-links"></a>
### लॉग लिंक

🔗 नियंत्रण प्रविष्टि के `locations` सरणी से स्रोत फ़ाइल:लाइन स्थानों को टर्मिनल पर प्रिंट करता है।

<a id="ui-plurals-tab"></a>
## UI बहुवचन टैब

बहुवचन-समूह प्रविष्टियों (`"plural": true` में `strings.json`) को सूचीबद्ध करता है। प्रत्येक पंक्ति एक स्थान के मूल रूपों (`one`, `other`, और स्थान-विशिष्ट रूप) को दर्शाती है।

<a id="filters-1"></a>
### फ़िल्टर

UI स्ट्रिंग टैब के समान, साथ ही:

| फ़िल्टर | उद्देश्य |
| --- | --- |
| **पूर्ण / अपूर्ण** | क्या चयनित स्थान के लिए सभी आवश्यक CLDR फ़ॉर्म मौजूद हैं |

अपूर्ण पंक्तियों में उस स्थान के लिए एक या अधिक आवश्यक फ़ॉर्म गायब हैं।

<a id="edit-1"></a>
### संपादित करें

1. एक पंक्ति पर संपादन आइकन पर क्लिक करें।
2. मोडल में प्रत्येक CLDR फ़ॉर्म को संपादित करें (प्रति फ़ॉर्म एक टेक्स्टएरिया)।
3. सहेजें — खाली फ़ॉर्म स्ट्रिंग सहेजने पर हटा दी जाती हैं।

प्रविष्टि का `models[locale]` `user-edited` पर सेट है। बाद में सादा `sync` या `translate-ui` चलाएँ (`--force` नहीं)।

<a id="other-columns"></a>
### अन्य कॉलम

- **फ़ॉर्म** — `one: "…"`, `other: "…"`, आदि प्रदर्शित करता है।
- **`zeroDigit` बैज** — जब स्रोत एक अंक-शून्य बहुवचन पैटर्न का उपयोग करता है तो केवल-पठन संकेतक।

आवश्यक फ़ॉर्म प्रति स्थान CLDR नियमों (`requiredPluralFormsByLocale`) से आते हैं।

<a id="delete-1"></a>
### हटाएँ

UI स्ट्रिंग के समान: प्रति-स्थान हटाना या **फ़िल्टर किया गया हटाएँ** थोक कार्रवाई।
