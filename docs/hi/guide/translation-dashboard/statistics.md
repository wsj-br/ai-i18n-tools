# सांख्यिकी

**सांख्यिकी** टैब आपके दस्तावेज़ कैश और UI स्ट्रिंग कैटलॉग के लिए केवल-पढ़ने वाले एग्रीगेट्स दिखाता है। डेटा कमांड लाइन पर `ai-i18n-tools statistics` से मेल खाता है।

इसका उपयोग यह जानने के लिए करें: *कितना अनुवाद किया गया है, किन मॉडलों का उपयोग किया गया था, और कहाँ कमियाँ हैं?*

<a id="documentation-cache"></a>
## दस्तावेज़ कैश

**सारांश कार्ड:**

| कार्ड | अर्थ |
| --- | --- |
| कुल सेगमेंट | सभी कैश किए गए दस्तावेज़ सेगमेंट पंक्तियाँ |
| बासी / सक्रिय | बनाए जाने के बाद कभी भी पुन: उपयोग नहीं किए गए सेगमेंट बनाम कम से कम एक बार पुन: उपयोग किए गए सेगमेंट |
| ट्रैक की गई फ़ाइलें / अद्वितीय फ़ाइलपाथ | कैश में फ़ाइल गणना |
| उपयोग किए गए मॉडल | विशिष्ट अनुवाद मॉडल |
| शब्दावली प्रविष्टियाँ | उपयोगकर्ता शब्दावली CSV में पंक्ति गणना (जब कॉन्फ़िगर किया गया हो) |

**तालिकाएँ:**

- **स्थानीयता के अनुसार सेगमेंट** — प्रति लक्ष्य स्थानीयता गणना, बासी/सक्रिय विभाजन के साथ
- **मॉडल के अनुसार सेगमेंट** — प्रति मॉडल गणना
- **मॉडल × स्थानीयता मैट्रिक्स** — पूर्ण क्रॉस-टैब (CLI `--max-columns` टर्मिनल आउटपुट पर सीमा के समान)

<a id="ui-strings"></a>
## UI स्ट्रिंग

जब `strings.json` उपलब्ध हो तो दिखाया गया है:

| अनुभाग | अर्थ |
| --- | --- |
| सादे बनाम बहुवचन गणना | कुल गैर-बहुवचन और बहुवचन-समूह प्रविष्टियाँ |
| प्रति स्थानीयता सादा कवरेज | प्रति स्थानीयता कितने सादे स्ट्रिंग का अनुवाद है |
| प्रति स्थानीयता बहुवचन पूर्णता | कितने बहुवचन समूहों में सभी आवश्यक CLDR फ़ॉर्म हैं |
| मॉडल / मॉडल × स्थानीयता द्वारा | दस्तावेज़ कैश के समान मैट्रिक्स लेआउट |

<a id="no-editing-on-this-tab"></a>
## इस टैब पर कोई संपादन नहीं

सांख्यिकी केवल देखने के लिए है। डेटा बदलने के लिए, अन्य डैशबोर्ड टैब का उपयोग करें या अनुवाद कमांड को फिर से चलाएँ, फिर डैशबोर्ड को पुनः लोड करें।

स्क्रिप्टेड आउटपुट के लिए, चलाएँ:

```bash
ai-i18n-tools statistics
# Optional: widen model × locale tables
# ai-i18n-tools statistics --max-columns 12
```
