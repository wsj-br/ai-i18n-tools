# दस्तावेज़ कैश

**दस्तावेज़** टैब आपके कॉन्फ़िगर किए गए `cacheDir` के तहत SQLite में संग्रहीत कैश किए गए दस्तावेज़ सेगमेंट अनुवादों को सूचीबद्ध करता है। प्रत्येक पंक्ति एक स्रोत सेगमेंट (फ़ाइलपाथ, लाइन हिंट और स्रोत हैश द्वारा पहचाना गया) है जिसे एक लक्ष्य लोकेल में अनुवादित किया गया है।

जब आप पूर्ण पाइपलाइन को फिर से चलाए बिना कैश किए गए दस्तावेज़ अनुवादों को **समीक्षा, ओवरराइड या साफ़** करना चाहते हैं तो इस टैब का उपयोग करें।

<a id="filters"></a>
## फ़िल्टर

| फ़िल्टर | उद्देश्य |
| --- | --- |
| **फ़ाइलपाथ चुनें** / **फ़ाइलनाम (आंशिक)** | एक फ़ाइल या एक पाथ सबस्ट्रिंग तक सीमित करें |
| **सभी लोकेल** | लक्ष्य लोकेल |
| **सभी मॉडल** | मॉडल जिसने अनुवाद बनाया |
| **स्रोत हैश** | सटीक सेगमेंट हैश |
| **स्रोत पाठ खोज** / **अनुवादित पाठ खोज** | सबस्ट्रिंग मिलान |
| **सभी प्रविष्टियाँ** | **बासी** (निर्माण के बाद कभी पुन: उपयोग नहीं किया गया) या **सक्रिय** (एक `last_hit_at` टाइमस्टैम्प है) |

फ़िल्टर बदलने के बाद **लागू करें** पर क्लिक करें। **साफ़ करें** सभी फ़िल्टर फ़ील्ड को रीसेट करता है।

<a id="edit-a-translation"></a>
## अनुवाद संपादित करें

1. एक पंक्ति पर संपादन आइकन पर क्लिक करें।
2. मोडल में अनुवादित पाठ बदलें और सहेजें।

कैश उस पंक्ति के लिए मॉडल `user-edited` को संग्रहीत करता है। `sync --force-update` या `translate-docs --force-update` चलाएँ ताकि ऑन-डिस्क मार्कडाउन आउटपुट कैश से मेल खाएँ।

यदि आपके रेपो में **स्रोत पाठ** बाद में बदलता है, तो सेगमेंट हैश बदल जाता है और पुराने पाठ के लिए मैन्युअल संपादन अगले अनुवाद रन पर अधिग्रहित हो जाते हैं।

<a id="delete-rows"></a>
## पंक्तियाँ हटाएँ

- **पंक्ति हटाएँ आइकन** — एक कैश प्रविष्टि (एक स्रोत हैश के लिए एक लोकेल) हटाता है।
- **फ़िल्टर किया गया हटाएँ** — वर्तमान फ़िल्टर से मेल खाने वाली सभी पंक्तियों को हटाता है (पुष्टि आवश्यक)।
- **फ़ाइलपाथ के लिए सभी हटाएँ** — चयनित फ़ाइलपाथ के लिए प्रत्येक कैश किए गए अनुवाद को हटाता है, जिसमें उस फ़ाइल के लिए संबंधित विफलता और मार्कडाउन समस्या पंक्तियाँ शामिल हैं।

बल्क डिलीट के बाद, गुम अनुवादों को फिर से उत्पन्न करने के लिए `translate-docs` या `sync` चलाएँ।

<a id="table-columns"></a>
## तालिका कॉलम

| कॉलम | अर्थ |
| --- | --- |
| **फ़ाइलपाथ** | स्रोत फ़ाइल के लिए कैश कुंजी |
| **लाइन #** | स्रोत फ़ाइल में लाइन संकेत |
| **स्रोत हैश** | स्रोत खंड पाठ का हैश |
| **स्रोत पाठ** | मूल खंड (स्रोत स्थानीय) |
| **स्थानीय** | लक्ष्य स्थानीय |
| **अनुवादित पाठ** | कैश किया गया अनुवाद |
| **मॉडल** | वह मॉडल जिसने अनुवाद तैयार किया (या `user-edited`) |
| **बनाया गया** | जब पंक्ति पहली बार लिखी गई थी |
| **अंतिम हिट** | इस कैश प्रविष्टि का अंतिम बार कब पुन: उपयोग किया गया था (लाल डैश = बासी) |

पृष्ठ संख्या डिफ़ॉल्ट रूप से प्रति पृष्ठ 50 पंक्तियों पर होती है (25 या 100 भी उपलब्ध हैं)।
