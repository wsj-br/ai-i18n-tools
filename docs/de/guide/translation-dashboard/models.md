# Modelle

Die Registerkarte **Modelle** stuft die Chat-Modelle des aktiven Anbieters ein, sodass Sie `translationModels` auswählen können, ohne IDs manuell kopieren zu müssen. Sie verwendet dasselbe Ranking wie [`suggest-models`](/de/reference/cli-commands/models#suggest-models). Eine exemplarische Vorgehensweise, die auch erklärt, warum die Liste mehr als ein Modell enthält, finden Sie unter [KI-Modelle](/de/guide/ai-models).

Die Seite ist in zwei Bereiche aufgeteilt. **Aktuelle Konfiguration** ist die bereits für den ausgewählten Anbieter gespeicherte Fallback-Kette. Die erste Zeile wird zuerst versucht. **Vorschläge** ist der gerankte Katalog, den Sie überprüfen, neu anordnen und zurückschreiben können. Das Ändern des Anbieters oder der Priorität lädt beide Bereiche neu. Eine konfigurierte ID, die im Katalog fehlt, wird weiterhin unter **Aktuelle Konfiguration** angezeigt und ist als „nicht im Katalog“ gekennzeichnet.

Wählen Sie **Qualität** oder **Preis**. Qualität sortiert nach dem ChrF- und Arena-Index und behandelt die Frontier-Spalte als Bezeichnung. Preis listet Stufe 1 vom günstigsten zum teuersten auf, dann Stufe 2 auf die gleiche Weise und so weiter. Es behält immer noch eine Qualitätsuntergrenze bei, sodass ein günstiges Modell ohne Messung unter Modellen bleibt, die Bewertungen haben. Wenn die Konfiguration mehr als einen Anbieter hat, erscheint ein **Anbieter**-Menü; der Standard ist der Anbieter, mit dem das Dashboard gestartet wurde (`provider` oder `-P` / `--provider` beim `dashboard`-Befehl). Optionale Gewichte finden Sie unter [`modelSuggestion`](/de/reference/configuration#modelsuggestion-optional).

Beide Bereiche teilen sich die Spalten für Bewertung und Preis: Modell-ID, Index (der Qualitätsscore mal 100), gemessener ChrF, gemessener Arena Score, Eingabepreis, Ausgabepreis, gemischter Preis in USD pro 1 Million Tokens und Frontier-Stufe. Eine fehlende Messung ist ein Gedankenstrich. Fahren Sie mit der Maus über eine Spaltenüberschrift in einem der Bereiche, um eine kurze Beschreibung dieser Spalte anzuzeigen. Fahren Sie mit der Maus über einen Frontier-Wert von 2 oder höher, um zu sehen, welches Modell der Stufe 1 diese Zeile dominiert. Die Zahl gibt an, wie tief diese Kette reicht, nicht wie weit der Index vom besten Modell entfernt ist. Eine ID, die ChrF, Arena Score und Token-Preise einer anderen Zeile wiederholt, wird aus den **Vorschlägen** weggelassen. Die kürzere ID wird beibehalten, und eine ID ohne Datum gewinnt gegenüber einer datierten. Ein konfigurierter Alias erscheint weiterhin unter **Aktuelle Konfiguration**. Eine exakte Übereinstimmung bei gemischtem Preis und Index teilt sich die Stufe. So lesen Sie die Spalte: [Lesen der Frontier-Spalte](/de/guide/ai-models#reading-the-frontier-column).

**Aktuelle Konfiguration** fügt eine Reihenfolgespalte hinzu. Diese Zahl ist der Platz des Modells in der gespeicherten Kette.

**Vorschläge** fügt Neuordnungs-Steuerelemente, ein Kontrollkästchen und einen Rang hinzu. Die Rangnummer ist der Platz des Modells in der vollständigen Rangliste, vor den unten stehenden Filtern. Ziehen Sie den Ziehpunkt einer Zeile oder verwenden Sie deren Auf- und Ab-Schaltflächen, um ihren Platz in dieser Tabelle zu ändern. **Aktualisieren** lädt die Rangfolge erneut.

Die Steuerelemente befinden sich in drei Karten. **Rangfolge** enthält das Prioritätsmenü (und das Anbieter-Menü, wenn die Konfiguration mehr als einen Anbieter hat). **Filter** enthält **Maximaler gemischter Preis**, **Minimales Index-Delta** und **Aktualisieren**. **Aktionen** enthält **JSON kopieren** und **Konfiguration aktualisieren**. Drücken Sie die Eingabetaste in einem Zahlenfeld, um die Tabelle zu aktualisieren. Das Ändern eines Menüs bewirkt dasselbe.

**Maximaler Mischpreis** behält Modelle, deren Mischpreis `(3 × input + output) / 4` pro 1 Mio. Tokens höchstens so viele USD beträgt. Ein Modell ohne Mischpreis wird weggelassen. **Minimale Index-Delta** behält ein Modell nur dann, wenn sein Index sich vom zuvor beibehaltenen Modell um mindestens so viele Punkte unterscheidet. Das erste verbleibende Modell wird immer beibehalten. Lassen Sie eines der Felder leer, um diesen Filter zu überspringen. Auf einer Qualitätsrangliste, setzen Sie beide vor **Konfiguration aktualisieren**: die Preisobergrenze hält einen Fallback innerhalb eines Budgets, und die Indexlücke verwirft ein Modell, das nur einen kleinen Schritt von dem darüberliegenden entfernt ist. Eine dominierte Zeile unter der Obergrenze kann trotzdem erhalten bleiben. Die Frontier-Spalte zeigt dies an.

Markieren Sie die gewünschten Modelle. Die Statuszeile zeigt an, wie viele ausgewählt sind, zum Beispiel `8 models selected.`. Die schmale Zahl in der Spaltenüberschrift des Kontrollkästchens (Standard 8) gibt an, wie viele führende Zeilen dieses Kontrollkästchen auswählt. Durch Aktivieren werden diese Zeilen ausgewählt. Durch Deaktivieren werden alle Kontrollkästchen deaktiviert. Die von oben nach unten markierten Zeilen bilden die Fallback-Reihenfolge. **Konfiguration aktualisieren** fordert eine Bestätigung an, kopiert die aktuelle Konfiguration in `ai-i18n-tools.config.{timestamp}.backup.json` daneben und schreibt dann diese Reihenfolge in `providers.<selected>.translationModels`. `uiModels` und `localeModels` bleiben unverändert. **JSON kopieren** legt dasselbe `{ "translationModels": [...] }`-Fragment in die Zwischenablage. `suggest-models --apply` schreibt die gleiche Art von Sicherung.

Beim ersten Laden werden languagebench, Arena und models.dev bei leerem Cache heruntergeladen, was einige Zeit in Anspruch nehmen kann. Spätere Ladevorgänge verwenden den 7-Tage-Cache unter `<cacheDir>/benchmark-scores.json`. Der Tab verfügt über keine Schaltfläche zum Aktualisieren. Aktualisieren Sie den Cache über die CLI mit `ai-i18n-tools suggest-models --refresh` und laden Sie anschließend den Tab neu. Derselbe Befehl kann die Liste ausgeben oder anwenden.
