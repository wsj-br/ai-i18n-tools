# モデル

「**モデル**」タブでは、アクティブなプロバイダーのチャットモデルがランク付けされているため、ID を手動でコピーすることなく `translationModels` を選択できます。このタブでは [`suggest-models`](/ja/reference/cli-commands/models#suggest-models) と同じランキングが使用されます。リストに複数のモデルが含まれる理由などの詳細な説明は、[AI モデル](/ja/guide/ai-models) をご覧ください。

**品質**または**価格**を選択します。品質はlanguagebenchのChrFとArena Scoreを優先します。価格は米ドルのレートが低いことを優先しつつ、品質の最低基準を維持します。設定に複数のプロバイダーがある場合、**プロバイダー**メニューが表示されます。デフォルトはダッシュボードの起動時に使用されたプロバイダー（`provider`、または`dashboard`コマンドでの`-P` / `--provider`）です。プロバイダーまたは優先順位を変更すると、テーブルが再読み込みされます。オプションの重み付けについては[`modelSuggestion`](/ja/reference/configuration#modelsuggestion)を参照してください。

テーブルの列は、並べ替えコントロール、チェックボックス、ランク、モデルID、インデックス（重み付けされたスコアの100倍）、測定されたChrF、測定されたアリーナスコア、および100万トークンあたりの入出力価格（米ドル）です。測定値がない場合は、emダッシュで示されます。ランク番号は、以下のフィルターを適用する前の、完全なランキングにおけるモデルの順位です。行のハンドルをドラッグするか、上下ボタンを使用して、このテーブル内での位置を変更します。**更新**すると、ランク順が再度読み込まれます。

コントロールは3つのカードに配置されています。**ランキング**には、優先度メニュー（設定に複数のプロバイダーがある場合はプロバイダーメニューも）があります。**フィルター**には、**最大出力価格**、**最小インデックスデルタ**、および**更新**があります。**アクション**には、**JSONをコピー**と**設定を更新**があります。数値フィールドでEnterキーを押すとテーブルが更新されます。メニューを変更した場合も同様です。

**最大出力価格**は、100万トークンあたりの出力価格が指定された米ドル以下であるモデルを保持します。出力価格がないモデルは除外されます。**最小インデックス差分**は、モデルのインデックスが、直前の保持されたモデルよりも指定されたポイント数以上低い場合にのみ、そのモデルを保持します。最初に残ったモデルは常に保持されます。いずれかのボックスを空のままにすると、そのフィルターはスキップされます。

使用するモデルにチェックを入れてください。ステータス行には、選択されている数が表示されます。例: `8 models selected.` チェックボックス列のヘッダーにある狭い数値（デフォルトは8）は、そのチェックが選択する先頭の行数を示します。チェックするとそれらの行が選択され、チェックを外すとすべてのチェックボックスがクリアされます。チェックされた行は上から下へとフォールバック順になります。**設定を更新**は確認を求め、現在の設定をその横の`ai-i18n-tools.config.{timestamp}.backup.json`にコピーしてから、その順序を`providers.<selected>.translationModels`に書き込みます。`uiModels`と`localeModels`は変更されません。**JSONをコピー**は同じ`{ "translationModels": [...] }`フラグメントをクリップボードにコピーします。`suggest-models --apply`は同様のバックアップを書き込みます。

初回読み込み時は、キャッシュが空の場合にlanguagebench、Arena、models.devをダウンロードするため、時間がかかることがあります。以降の読み込みでは、`<cacheDir>/benchmark-scores.json`にある7日間のキャッシュが再利用されます。このタブには更新ボタンはありません。CLIで`ai-i18n-tools suggest-models --refresh`を使用してキャッシュを更新してから、タブを再読み込みしてください。同じコマンドでリストを表示または適用することもできます。
