# モデル

「**モデル**」タブでは、アクティブなプロバイダーのチャットモデルがランク付けされているため、ID を手動でコピーすることなく `translationModels` を選択できます。このタブでは [`suggest-models`](/ja/reference/cli-commands/models#suggest-models) と同じランキングが使用されます。リストに複数のモデルが含まれる理由などの詳細な説明は、[AI モデル](/ja/guide/ai-models) をご覧ください。

ページは2つのペインに分かれています。**現在の設定**は、選択されたプロバイダーに対して既に保存されているフォールバックチェーンです。最初の行が最初に試行されます。**提案**は、確認、並べ替え、および書き戻しができるランク付けされたカタログです。プロバイダーまたは優先度を変更すると、両方のペインが再読み込みされます。カタログにない設定済みのIDは、**現在の設定**に引き続き表示され、「カタログにありません」とマークされます。

**品質**または**価格**を選択します。品質はChrFとArenaインデックスでソートされ、フロンティア列をラベルとして扱います。価格は、ティア1を最も安いものから最も高いものへ、次にティア2を同様に、といった順にリストします。品質の下限は維持されるため、測定値のない安価なモデルは、スコアを持つモデルよりも下に位置します。設定に複数のプロバイダーがある場合、**プロバイダー**メニューが表示されます。デフォルトは、ダッシュボードが開始されたプロバイダーです（`provider`、または`dashboard`コマンドでの`-P` / `--provider`）。オプションの重みは[`modelSuggestion`](/ja/reference/configuration#modelsuggestion-optional)にあります。

両方のペインでスコアと価格の列が共有されます。これには、モデルID、インデックス（品質スコアの100倍）、測定されたChrF、測定されたArenaスコア、入力価格、出力価格、100万トークンあたりのUSDでのブレンド価格、およびフロンティアティアが含まれます。測定値がない場合は、emダッシュで示されます。いずれかのペインで列ヘッダーにカーソルを合わせると、その列の簡単な説明が表示されます。フロンティア値が2以上の場合は、その行を支配するティア1モデルを確認できます。その数値はチェーンの深さを示し、インデックスが最適なモデルからどれだけ離れているかを示すものではありません。他の行のChrF、Arenaスコア、およびトークン価格を繰り返すIDは、**提案**から除外されます。短いIDが保持され、日付のないIDは日付のあるIDよりも優先されます。設定済みのエイリアスは、**現在の設定**に引き続き表示されます。ブレンド価格とインデックスが完全に一致する場合、ティアは共有されます。列の読み方：[フロンティア列の読み方](/ja/guide/ai-models#reading-the-frontier-column)。

**現在の設定**には、順序列が追加されます。その数値は、保存されたチェーンにおけるモデルの位置を示します。

**提案**には、並べ替えコントロール、チェックボックス、およびランクが追加されます。ランク番号は、以下のフィルターが適用される前の、完全なランキングにおけるモデルの位置を示します。行のハンドルをドラッグするか、上下ボタンを使用して、このテーブル内での位置を変更します。**更新**は、ランク順を再度読み込みます。

コントロールは3つのカードに配置されています。**ランキング**には優先度メニュー（設定に複数のプロバイダーがある場合はプロバイダーメニューも）があります。**フィルター**には**最大ブレンド価格**、**最小インデックス差分**、および**更新**があります。**アクション**には**JSONをコピー**と**設定を更新**があります。数値フィールドでEnterキーを押すと、テーブルが更新されます。メニューを変更しても同様です。

**ブレンド価格の最大値**は、100万トークンあたりのブレンド価格が`(3 × input + output) / 4`米ドル以下であるモデルを保持します。ブレンド価格がないモデルは除外されます。**最小インデックス差**は、インデックスが以前に保持されたモデルと少なくともその点数分異なる場合にのみ、モデルを保持します。最初に残ったモデルは常に保持されます。いずれかのボックスを空のままにすると、そのフィルターはスキップされます。品質ランキングでは、**設定を更新**する前に両方を設定します。価格上限は、予算内でフォールバックを維持し、インデックスギャップは、その上位モデルからわずかな差しかないモデルを除外します。上限下の支配された行は、依然として残る可能性があります。それを示すのがフロンティア列です。

使用するモデルにチェックを入れてください。ステータス行には、選択されている数が表示されます。例: `8 models selected.` チェックボックス列のヘッダーにある狭い数値（デフォルトは8）は、そのチェックが選択する先頭の行数を示します。チェックするとそれらの行が選択され、チェックを外すとすべてのチェックボックスがクリアされます。チェックされた行は上から下へとフォールバック順になります。**設定を更新**は確認を求め、現在の設定をその横の`ai-i18n-tools.config.{timestamp}.backup.json`にコピーしてから、その順序を`providers.<selected>.translationModels`に書き込みます。`uiModels`と`localeModels`は変更されません。**JSONをコピー**は同じ`{ "translationModels": [...] }`フラグメントをクリップボードにコピーします。`suggest-models --apply`は同様のバックアップを書き込みます。

初回読み込み時は、キャッシュが空の場合にlanguagebench、Arena、models.devをダウンロードするため、時間がかかることがあります。以降の読み込みでは、`<cacheDir>/benchmark-scores.json`にある7日間のキャッシュが再利用されます。このタブには更新ボタンはありません。CLIで`ai-i18n-tools suggest-models --refresh`を使用してキャッシュを更新してから、タブを再読み込みしてください。同じコマンドでリストを表示または適用することもできます。
