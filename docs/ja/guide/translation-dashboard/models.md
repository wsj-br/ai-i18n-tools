# モデル

**モデル**タブでは、アクティブなプロバイダーのチャットモデルがランク付けされるため、IDを手動でコピーすることなく`translationModels`を選択できます。これは[`suggest-models`](/ja/reference/cli-commands/models#suggest-models)と同じランキングを使用しています。

**品質**または**価格**を選択します。品質はlanguagebenchのChrFとArena Scoreを優先します。価格は米ドルのレートが低いことを優先しつつ、品質の最低基準を維持します。設定に複数のプロバイダーがある場合、**プロバイダー**メニューが表示されます。デフォルトはダッシュボードの起動時に使用されたプロバイダー（`provider`、または`dashboard`コマンドでの`-P` / `--provider`）です。プロバイダーまたは優先順位を変更すると、テーブルが再読み込みされます。オプションの重み付けについては[`modelSuggestion`](/ja/reference/configuration#modelsuggestion)を参照してください。

テーブルの列は、ランク、モデルID、インデックス（重み付けされたスコアに100を掛けたもの）、測定されたChrF、測定されたArena Score、および100万トークンあたりの米ドルでの入力/出力価格です。測定値がない場合は全角ダッシュで表示されます。ランク番号は、以下のフィルターを適用する前の完全なランキングにおけるモデルの順位です。

**最大出力価格**は、100万トークンあたりの出力価格が指定した米ドル以下のモデルを保持します。出力価格がないモデルは除外されます。**最小インデックス差**は、インデックスが直前の保持モデルより指定したポイント数以上低い場合にのみモデルを保持します。最初に残ったモデルは常に保持されます。いずれかのボックスを空にすると、そのフィルターはスキップされます。いずれかの値を変更すると、テーブルが再読み込みされます。

必要なモデルにチェックを入れます。**上位を使用**（デフォルトは5）は、フィルターされたリストの最初のN行を選択し、その順序をリセットします。選択したIDを上下に移動して、フォールバック順序を設定します。**設定を更新**は、その順序を`providers.<selected>.translationModels`に書き込み、`uiModels`と`localeModels`は変更しません。**JSONをコピー**は、同じ`{ "translationModels": [...] }`フラグメントをクリップボードにコピーします。

初回読み込み時は、キャッシュが空の場合にlanguagebench、Arena、models.devをダウンロードするため、時間がかかることがあります。以降の読み込みでは、`<cacheDir>/benchmark-scores.json`にある7日間のキャッシュが再利用されます。このタブには更新ボタンはありません。CLIで`ai-i18n-tools suggest-models --refresh`を使用してキャッシュを更新してから、タブを再読み込みしてください。同じコマンドでリストを表示または適用することもできます。
