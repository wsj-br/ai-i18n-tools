<a id="usage--costs"></a>
# 利用とコスト

**使用量とコスト**タブでは、このプロジェクトで行われた請求対象のモデルAPI呼び出し（後に破棄された再試行を含む）について、トークン数と米ドル建ての合計コストで要約しています。

同じ集計結果はコマンドラインで `ai-i18n-tools usage` として利用できます。

これを使って、*何回の呼び出しを行ったか、どのモデルと操作がトークンを消費したか、そしてコストはいくらだったか* という疑問に答えることができます。

<a id="what-is-recorded"></a>
## 記録される内容

各詳細行は、使用量を返した 1 つの HTTP 完了です（後にパースやスクリプト、品質の理由で翻訳が拒否され、次のフォールバックモデルが試行された場合も含みます）。課金対象のレスポンスボディを生成しなかった通信の失敗は記録されません。

APIを呼び出すコマンドが完了した後、**UTC暦日での丸7日間**（本日の7日前のUTC 00:00起算）より古い行は月次合計（`api_totals`）に集約され、詳細ログから削除されます。直近1週間は個別の`api_calls`行として保持されます。サマリーテーブルは、選択した期間について両方のソースを組み合わせて表示します。

<a id="cost-reporting"></a>
## コスト報告

各呼び出し、サマリーカード、およびテーブルには**1つの**USDコストが表示されます。

1. レスポンスに含まれていた場合のプロバイダーの`usage.cost`（現在はOpenRouter）。
2. それ以外の場合は、`providers.<name>.modelPricing`またはプロバイダー全体の`pricing`デフォルト値の金額を、その呼び出しの入力トークンと出力トークンに適用します。

新しい呼び出しでは、その金額が`api_calls`行に保存されます。コストなしで保存された古い行は、レポートを開いた時点で同じ方法で価格計算され、同じCost数値に追加されます — 2番目の列として表示されることはありません。どちらのソースも適用されない場合、セルは`—`となり、`$0.00`になることはありません。後から設定済みのレートを変更しても、すでにコストが保存されている行は書き換えられません。月次ロールアップでも、コストが保存された呼び出しのカウント（`ncost_acc` / `ncost_dis`）を保持するため、圧縮後も`$0.00`は「unknown」と区別されます。

<a id="filters"></a>
## フィルター

期間、プロバイダー、モデル、操作（`translate-docs`, `translate-ui`, `translate-json`, `translate-svg`, `proofread-ui`, `bench-models`）、ロケール、および結果（採用 vs 破棄）でフィルターします。

期間:

- 短い範囲（`Last 30 minutes` から `Last 30 days`）はローリング期間を使用します。**Usage over time** はその範囲内に詳細が残っている各 UTC 暦日につき 1 行を表示します。
- `Last 2 months` / `Last 3 months` は現在の暦月の初日の 00:00 UTC から 1 / 2 か月前を開始とします。**Usage over time** は保持された日次行に加えて各月につき 1 行を表示します。
- `All time` にはすべての月次合計と保持された日次行が含まれます。

古い使用量を削除するには、**これより古いエントリを削除**（`> 1 month`、`> 2 months`、`> 3 months`、`> 6 months`、`> 1 year`、または`all data (clear)`）から期間を選択し、**データを削除**をクリックします。メニューの初期値は`-`であり、期間が選択されるまで**データを削除**は無効のままです。同じ期間を`ai-i18n-tools usage --clear [--older-than 1mo|2mo|3mo|6mo|1y|all]`として利用できます。暦月のカットオフでは、当月（`1mo`）または当月とそれ以前の月が保持されます。

<a id="command-line"></a>
## コマンドライン

```bash
ai-i18n-tools usage
# ai-i18n-tools usage --since 7d --operation translate-docs
# ai-i18n-tools usage --since 2mo
# ai-i18n-tools usage --clear --older-than 3mo --dry-run
```
