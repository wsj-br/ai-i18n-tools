# 用語集

**用語集**タブでは、ユーザー用語集CSV（config内の`glossary.userGlossary`）を編集します。ここでのエントリは、`translate-ui`、`proofread-ui`、`translate-docs`向けの用語ヒントです（共有用語集経由）。コンパクトなUIラベルの略語（例：`Size` → `Tam` / `Tam.`）はUI翻訳用に保持されますが、ドキュメントプロンプトの構築時にはスキップされるため、markdown/MDX内でモデルが独自の<code v-pre>{{…}}</code>トークンを生成するよう誘導することはありません。

`glossary.userGlossary`が設定されていない場合、タブは非表示になります。

<a id="csv-columns"></a>
## CSV列

| 列 | 意味 |
| --- | --- |
| **原文の文字列** | ソースの用語またはフレーズ |
| **ロケール** | ターゲットロケール、またはすべてのロケールの場合は`*` |
| **翻訳** | 推奨される翻訳 |
| **コンテキスト** | 意味や使用方法に関するオプションのソース言語の説明。この用語が現在のバッチに一致した場合にのみ送信されます。 |
| **強制** | チェックされている場合、用語は指定されたとおりに正確に翻訳されなければなりません |

<a id="add-a-row"></a>
## 行を追加する

タブの上部にあるフォームを使用します。

1. **原文**、**ロケール**（`*`またはターゲットロケールコード）、**翻訳**を入力します。
2. 必要に応じて**コンテキスト**（使用上の注意）を追加し、**強制**にチェックを入れます。
3. **追加**をクリックします。

CSVファイルは、まだ存在しない場合、最初に追加されたときに作成されます。

<a id="edit-or-delete"></a>
## 編集または削除

- **インライン編集** — テーブル内のフィールドを直接変更し、その行の**保存**をクリックします。
- **削除** — 削除コントロールで行を削除します。

変更は次回の`translate-ui`、`proofread-ui`、`translate-docs`、または`sync`の実行時に反映されます。**コンテキスト**のメモ（または設定内の`glossary.contextFiles`）を編集すると、影響を受けるロケールのキャッシュされた翻訳が自動的に更新されます — `--force`は不要です。

コンテキストファイルは、簡潔なMarkdownまたはプレーンテキストの概要として、翻訳対象の`docs[]`ツリーの外に配置してください。このテキストは一致するすべてのリクエストでLLMに送信されるため、機密情報や個人データは含めないでください。これらのファイルとCSVの作成方法については、[用語集](/ja/guide/glossary)で説明しています。

<a id="filters"></a>
## フィルター

**原文**、**ロケール**（`*`を含む）、**翻訳テキスト**、または**コンテキスト**の部分文字列でフィルタリングし、**適用**をクリックします。

<a id="dashboard-edits-and-glossary-auto-add"></a>
## ダッシュボードの編集と用語集の自動追加

**UI文字列**または**UI複数形**タブでUI文字列を修正すると、`glossary.autoAddUserEditedToGlossary`が`true`の場合、次の`translate-ui`実行でその修正が用語集に自動的に追加されることがあります。用語集タブを使用して、自動追加された行を確認、調整、または削除します。
