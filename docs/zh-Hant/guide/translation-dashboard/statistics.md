# 統計資料

「**統計資料**」分頁顯示文件快取和 UI 字串目錄的唯讀彙總。資料與命令列上的 `ai-i18n-tools statistics` 相符。

使用它來回答：*翻譯了多少內容、使用了哪些模型以及存在哪些空白？*

<a id="documentation-cache"></a>
## 文件快取

**摘要卡：**

| 卡片 | 意義 |
| --- | --- |
| 總區段數 | 所有快取的文件區段列 |
| 過時/啟用中 | 自建立以來從未重複使用與至少重複使用一次的區段 |
| 追蹤檔案/唯一檔案路徑 | 快取中的檔案計數 |
| 使用的模型 | 不同的翻譯模型 |
| 詞彙表項目 | 使用者詞彙表 CSV 中的列數 (設定後) |

**表格：**

- **依地區設定的區段** — 每個目標地區設定的計數，包含過時/啟用中細目
- **依模型的區段** — 每個模型的計數
- **模型 × 地區設定矩陣** — 完整交叉表 (與 CLI `--max-columns` 終端機輸出限制相同)

<a id="ui-strings"></a>
## UI 字串

當 `strings.json` 可用時顯示：

| 區段 | 意義 |
| --- | --- |
| 單數與複數計數 | 總非複數和複數群組項目 |
| 每個地區設定的單數涵蓋範圍 | 每個地區設定有多少單數字串有翻譯 |
| 每個地區設定的複數完整性 | 有多少複數群組具有所有必要的 CLDR 形式 |
| 依模型/模型 × 地區設定 | 與文件快取相同的矩陣佈局 |

<a id="no-editing-on-this-tab"></a>
## 此分頁無法編輯

統計資料為唯讀。若要變更資料，請使用其他儀表板分頁或重新執行翻譯命令，然後重新載入儀表板。

若要執行指令碼輸出，請執行：

```bash
ai-i18n-tools statistics
# Optional: widen model × locale tables
# ai-i18n-tools statistics --max-columns 12
```
