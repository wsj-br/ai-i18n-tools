# 文件快取

「**文件**」分頁列出了儲存在您設定的 `cacheDir` 中 SQLite 資料庫裡的快取文件區段翻譯。每一列代表一個來源區段（由檔案路徑、行提示和來源雜湊識別），翻譯成一個目標語系。

當您想要**檢閱、覆寫或清理**快取的文件翻譯，而無需重新執行整個管線時，請使用此分頁。

<a id="filters"></a>
## 篩選器

| 篩選器 | 用途 |
| --- | --- |
| **選取檔案路徑** / **檔案名稱（部分）** | 縮小到單一檔案或路徑子字串 |
| **所有語系** | 目標語系 |
| **所有模型** | 產生翻譯的模型 |
| **來源雜湊** | 精確的區段雜湊 |
| **來源文字搜尋** / **翻譯文字搜尋** | 子字串符合 |
| **所有項目** | **過時**（自建立以來從未重複使用）或**啟用中**（具有 `last_hit_at` 時間戳記） |

更改篩選器後，按一下**套用**。**清除**會重設所有篩選欄位。

<a id="edit-a-translation"></a>
## 編輯翻譯

1. 按一下列上的編輯圖示。
2. 在模式視窗中更改翻譯文字並儲存。

快取會儲存該列的模型 `user-edited`。執行 `sync --force-update` 或 `translate-docs --force-update`，以便磁碟上的 Markdown 輸出與快取相符。

如果您的儲存庫中的**來源文字**稍後發生變更，區段雜湊也會變更，並且針對舊文字的手動編輯將在下次翻譯執行時被取代。

<a id="delete-rows"></a>
## 刪除列

- **列刪除圖示** — 移除一個快取項目（一個來源雜湊的一個語系）。
- **刪除已篩選的** — 移除所有符合目前篩選條件的列（需要確認）。
- **刪除檔案路徑的所有項目** — 移除所選檔案路徑的所有快取翻譯，包括該檔案的相關失敗和 Markdown 問題列。

大量刪除後，執行 `translate-docs` 或 `sync` 以重新產生遺失的翻譯。

<a id="table-columns"></a>
## 表格欄位

| 欄位 | 意義 |
| --- | --- |
| **檔案路徑** | 來源檔案的快取鍵 |
| **行號** | 原始檔案中的行提示 |
| **來源雜湊** | 來源區段文字的雜湊值 |
| **來源文字** | 原始區段（來源語系） |
| **語系** | 目標語系 |
| **翻譯文字** | 快取翻譯 |
| **模型** | 產生翻譯的模型（或 `user-edited`） |
| **建立時間** | 首次寫入此列的時間 |
| **上次命中** | 此快取項目上次重複使用的時間（紅色破折號 = 過期） |

分頁預設為每頁 50 列（也可選擇 25 或 100 列）。

<a id="log-links"></a>
## 記錄連結

行中的 🔗 控制項會要求伺服器將檔案：行提示列印到執行儀表板的終端機。使用它可以在編輯器中開啟正確的原始碼位置。
