# ai-i18n-tools 1.13.1 Release Notes

## Highlights

- **.NET examples on GitHub Releases:** Each release attaches `ai-i18n-tools-dotnet-examples.zip` with `examples/dotnet-console`, `examples/dotnet-resx`, and `assets/dotnet`. Build directories `bin` and `obj` are left out. The archive is a release asset only; the npm tarball and the standalone executable stay the same.

## Why this release matters

Version 1.13.1 ships the .NET console and `.resx` examples as a GitHub Release archive, so you can try the 1.13.0 .NET workflow without cloning the repository.
