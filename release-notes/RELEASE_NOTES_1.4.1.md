# ai-i18n-tools 1.4.1 Release Notes

## Highlights

- **Dependency fix:** Downgraded `express` from `^5.2.1` to `^4.22.1` for Docusaurus 3.x compatibility.

## Why this release matters

This patch release resolves a compatibility issue where `express` v5 conflicted with Docusaurus 3.x, ensuring the package works correctly with the latest Docusaurus ecosystem.
